# Architectural Module Extraction

This directory contains the scripts, LLM-generated results, and evaluation files for extracting architectural modules from software architecture documentation using Large Language Models (LLMs).

It serves as the initial stage of the framework for identifying documented architectural modules from existing, potentially incomplete or outdated architectural documentation.

## Structure

```text
1Module_extraction/
├── LLM_responses/
│   ├── gpt_4o/
│   └── deepseek-v3/
├── extract.py
├── evaluate_module_extraction.py
├── project_statistics-gpt_4o.csv
└── project_statistics-deepseek-v3.csv
```

### `extract.py`

The `extract.py` script invokes LLMs to extract architectural module information from the input architecture documentation.

The extracted modules for each project are stored in the corresponding model directory under `LLM_responses/`.

### `LLM_responses/`

The `LLM_responses` directory contains the architectural module extraction results generated by different LLMs.

Currently, the directory includes results produced by:

- GPT-4o
- DeepSeek-V3

The results are organized by LLM, project, and experiment. For example:

```text
LLM_responses/
└── gpt_4o/
    └── <project_name>/
        ├── output_1.txt
        ├── output_2.txt
        └── ...
```

Each output file contains the architectural modules extracted from the corresponding project's architecture documentation.

### `evaluate_module_extraction.py`

The `evaluate_module_extraction.py` script evaluates the LLM-generated module extraction results against the corresponding ground-truth architectural modules.

For each experiment, the script calculates:

- Precision
- Recall
- F1 score

The evaluation is performed across multiple experiments. The script also calculates standard deviation and variance of the precision, recall and F1 score .

### `project_statistics-<model-name>.csv`

Running `evaluate_module_extraction.py` generates model-specific evaluation result files, such as:

```text
project_statistics-gpt_4o.csv
project_statistics-deepseek-v3.csv
```

These files summarize the module extraction performance for each evaluated project and LLM.



## Running Module Extraction

Run the extraction script from the `1Module_extraction` directory:

```bash
python extract.py
```

The generated LLM responses are saved under the corresponding directories in `LLM_responses/`.

## Running the Evaluation

Run the evaluation script from the `1Module_extraction` directory:

```bash
python evaluate_module_extraction.py
```

The script compares the extracted modules with the ground-truth modules and generates the corresponding `project_statistics-<model-name>.csv` files.
