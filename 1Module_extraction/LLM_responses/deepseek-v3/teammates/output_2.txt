Here are the distinct architecture modules extracted from the documentation, along with their responsibilities:

module name: UI (Frontend), module description: Handles user interactions and renders the single-page application built with Angular, consisting of HTML, CSS, and JavaScript/TypeScript. Processes user-invoked requests and communicates with the backend via AJAX.

module name: UI Server (Backend), module description: Serves as the entry point for backend logic, implemented as REST-ful controllers. Processes HTTP requests, applies filters (e.g., CSRF checks), and routes requests to appropriate servlets (WebPageServlet for initial page loads, WebApiServlet for AJAX requests).

module name: Logic, module description: Manages core business logic including entity relationships, transactions, input sanitization, and access control. Provides APIs for UI interaction and integrates with Storage and external services (email, task queues).

module name: Storage, module description: Performs CRUD operations on data entities using GAE Datastore. Validates data, abstracts datastore complexities, and returns data transfer objects. Contains minimal business logic beyond direct persistence operations.

module name: Common, module description: Provides shared utilities across the application including helper classes, custom exceptions, and data transfer objects used for inter-component communication.

module name: Test Driver, module description: Facilitates automated testing at all levels (unit, integration, system) using TestNG for Java and Jest for JavaScript. Includes test infrastructure, helpers, and test cases for all components.

module name: E2E (End-to-End), module description: Performs system-level testing by interacting with the application as a whole through browsers (using Selenium) or REST API calls. Includes page objects, test cases, and load/performance testing capabilities.

module name: Client, module description: Provides administrative tools and scripts that connect directly to the backend for tasks like data migration and statistical analysis, bypassing the standard UI.

module name: Automated Processing, module description: Handles GAE-initiated requests (cron jobs and task queues) for scheduled operations like reminders and long-running tasks. Includes specialized servlets and actions for automated processing.
