Here are the distinct architecture modules extracted from the documentation, along with their responsibilities:

module name: UI (Frontend), module description: Handles user interactions and renders the single-page application built with Angular, consisting of HTML, CSS, and JavaScript/TypeScript. Processes user-invoked requests and manages client-side logic like input validation and AJAX calls to the backend.

module name: UI Server (Backend), module description: Serves as the entry point for backend logic via REST-ful controllers. Processes HTTP requests, applies filters (e.g., CSRF checks), and routes requests to appropriate servlets (WebPageServlet for initial page load, WebApiServlet for AJAX requests). Implements authentication/authorization checks.

module name: Logic, module description: Manages core business logic including entity relationships, transactions, input sanitization, and access control. Acts as a facade between UI and Storage, with subcomponents for email generation, task queuing, and API integrations (e.g., email services).

module name: Storage, module description: Performs CRUD operations on data entities using GAE Datastore (NoSQL). Validates entity state, abstracts datastore complexities, and returns data transfer objects (Attributes). Contains minimal logic beyond basic persistence operations.

module name: Common, module description: Provides shared utilities across the application, including helper classes, custom exceptions, and data transfer objects (DTOs) for inter-component communication.

module name: Test Driver, module description: Facilitates automated testing with TestNG (Java) and Jest (JavaScript). Includes infrastructure for unit, integration, and system tests across all components (logic, storage, web API, etc.).

module name: E2E (End-to-End), module description: Conducts system-level tests via Selenium (browser automation) and REST API calls. Includes page object abstractions and load/performance testing capabilities.

module name: Client, module description: Contains administrative scripts for direct backend access (bypassing UI), used for data migration, statistics calculation, and other maintenance tasks.

module name: Automated Processing, module description: Handles GAE-invoked requests (cron jobs/task queues) for scheduled tasks like email reminders and long-running operations. Enforces admin-only privileges for these actions.
