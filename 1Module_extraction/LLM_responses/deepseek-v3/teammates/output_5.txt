**module name:** UI (Frontend)  
**module description:** Handles user interactions and renders the single-page application (SPA) built with Angular. Consists of HTML, CSS, and TypeScript (compiled to JavaScript) for client-side logic, including input validation and AJAX requests to the backend.  

**module name:** UI Server (Backend)  
**module description:** Processes HTTP requests via REST-ful controllers (e.g., `WebPageServlet`, `WebApiServlet`). Manages user-invoked and automated requests, applies access control (CSRF, authentication), and delegates business logic to the Logic component.  

**module name:** Logic  
**module description:** Implements core business rules, including entity relationship management, transaction handling, input sanitization, and access control checks. Acts as a facade (`Logic` class) for other submodules (e.g., `GateKeeper`, `EmailSender`, `TaskQueuer`).  

**module name:** Storage  
**module description:** Performs CRUD operations on GAE Datastore (NoSQL). Validates entity data, abstracts datastore complexities, and returns data transfer objects (DTOs) like `CourseAttributes`. Excludes cascade logic (handled by Logic).  

**module name:** Common  
**module description:** Provides shared utilities across components, including DTOs (e.g., `DataBundle`), custom exceptions, and helper classes (e.g., for JSON parsing).  

**module name:** Test Driver  
**module description:** Facilitates automated testing (unit, integration, system) using TestNG (Java), Jest (JavaScript), and HttpUnit (servlet-level). Includes test infrastructure and helpers.  

**module name:** E2E (End-to-End)  
**module description:** Conducts system-level tests via Selenium (browser automation) and REST API calls. Includes load/performance testing (experimental) and page object abstractions.  

**module name:** Client  
**module description:** Enables direct backend access for administrative tasks (e.g., data migration, statistics) via scripts, bypassing the UI. Uses `remoteapi` for connections.  

**module name:** Automated Actions  
**module description:** Handles GAE-triggered tasks (cron jobs, task queues) like feedback reminders. Executed via `AutomatedServlet` with privilege checks.
