module name: Facade, module description: Server-side web front end that delivers websites, manages user sessions, and handles user interactions including browsing, downloading, and uploading audio files.  
module name: MediaManagement, module description: Central business logic component that coordinates communication between other components, processes download requests, and manages audio file retrieval and forwarding.  
module name: UserManagement, module description: Handles user registration, authentication, and password hashing/salting for secure login.  
module name: UserDBAdapter, module description: Encapsulates database access for user data, creates queries for user requests, and manages salted password hashes.  
module name: TagWatermarking, module description: Re-encodes and digitally watermarks audio files to associate them with user IDs for copyright protection.  
module name: Packaging, module description: Archives multiple audio files into a single compressed file for batch downloads.  
module name: ReEncoder, module description: Converts audio file bit rates to reduce file sizes during processing.  
module name: AudioAccess, module description: Manages queries and retrieval of audio file meta-data from the database.  
module name: MediaAccess, module description: Handles storage and retrieval of audio files from predefined locations and fetches associated meta-data for downloads.  
module name: Database, module description: Stores user information and audio file meta-data (e.g., name, genre) and executes queries for data retrieval.  
module name: DataStorage, module description: Dedicated storage for audio files, decoupled from the database, where files are stored unchanged during uploads.
