module name: Facade, module description: Server-side web front end that delivers websites, manages user sessions, and handles user interactions including browsing, downloading, and uploading audio files.  
module name: MediaManagement, module description: Central business logic component that coordinates communication between other components, processes download requests, and manages audio file retrieval and forwarding.  
module name: UserManagement, module description: Handles user registration, authentication, and password hashing/salting for secure login.  
module name: UserDBAdapter, module description: Encapsulates database access for user data, creates queries for user requests, and interacts with the Database component.  
module name: TagWatermarking, module description: Digitally watermarks re-encoded audio files to associate them with user IDs for copyright protection.  
module name: Packaging, module description: Archives multiple audio files into a single compressed file for batch downloads.  
module name: ReEncoder, module description: Converts audio file bit rates, potentially reducing file sizes during processing.  
module name: AudioAccess, module description: Encapsulates database access for audio file meta-data, fetches lists of available files, and handles meta-data queries.  
module name: MediaAccess, module description: Manages storage and retrieval of audio files from DataStorage, including fetching meta-data and handling uploads/downloads.  
module name: Database, module description: Stores user information, audio file meta-data (e.g., name, genre), and salted password hashes.  
module name: DataStorage, module description: Dedicated storage location (e.g., file server or local disk) for audio files, decoupled from the database.
