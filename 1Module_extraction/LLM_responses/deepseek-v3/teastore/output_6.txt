module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, and manages cookie logic. Also includes a status page displaying service instance information.  
module name: Image Provider, module description: Delivers images to the WebUI as base64-encoded strings, matches product IDs or UI names to image identifiers, and handles image scaling/caching with an LFU strategy.  
module name: Auth Service, module description: Handles user authentication and session validation using BCrypt for passwords and SHA512 for session integrity checks via cookies.  
module name: Persistence Service, module description: Manages access to the relational database, performs CRUD operations via JPA ORM (EclipseLink), and acts as a caching layer with a second-level entity cache.  
module name: Recommender Service, module description: Generates personalized product recommendations using Slope One (item-based collaborative filtering) or fallback popularity-based algorithms, with training based on user orders and cart data.  
module name: Registry, module description: Tracks service instances, their locations, and availability via heartbeat signals, ensuring a single registry instance per TeaStore deployment for simplicity.
