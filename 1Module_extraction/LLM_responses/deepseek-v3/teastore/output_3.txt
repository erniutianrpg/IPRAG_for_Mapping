module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, and manages cookie logic. Also includes a status page displaying service instance information.  
module name: Image Provider, module description: Delivers images to the WebUI as base64-encoded strings, matches product IDs or UI names to image identifiers, and handles scaling/caching (using LFU strategy) for efficient delivery.  
module name: Auth Service, module description: Handles user authentication and session validation using BCrypt for passwords and salted SHA512 hashes for session integrity checks.  
module name: Persistence Service, module description: Manages access to the relational database, maps entities to JSON objects using JPA ORM, and provides CRUD operations. Includes a second-level entity cache.  
module name: Recommender Service, module description: Generates personalized product recommendations using Slope One (item-based collaborative filtering) or fallback popularity-based algorithms. Supports CPU/memory-intensive variants and order-based nearest-neighbor approaches.  
module name: Registry, module description: Tracks service instances, their locations, and online status via heartbeats. Ensures single-instance configuration for simplicity in parallel TeaStore deployments.
