module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, manages cookies, and displays a status page with service instance details.  
module name: Image Provider, module description: Delivers images to the WebUI as base64-encoded strings, matches product IDs or UI names to image identifiers, handles image scaling and caching, and returns a "not found" image if requested resources are unavailable.  
module name: Auth Service, module description: Handles user and session authentication, hashes passwords using BCrypt, validates sessions using salted SHA512 hashes, and prevents session tampering.  
module name: Persistence Service, module description: Provides CRUD operations for persistent entities, maps relational database data to JSON objects using EclipseLink JPA, and acts as a caching layer via JPA's second-level cache.  
module name: Recommender Service, module description: Generates personalized product recommendations based on user behavior (shopping cart, orders, item views), employs Slope One collaborative filtering or fallback popularity-based algorithms, and offers CPU-intensive and memory-intensive recommendation variants.  
module name: Registry, module description: Tracks online service instances and their locations, manages service registration and heartbeats, and marks services as offline if heartbeats are missed for over 10 seconds. Ensures single-instance configuration for simplicity in multi-instance TeaStore deployments.
