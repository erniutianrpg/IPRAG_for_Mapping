module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, and manages cookie logic. Also includes a status page displaying service instance counts and hosts.  
module name: Image Provider, module description: Delivers images to the WebUI as base64-encoded strings, matches product IDs or UI names to image identifiers, and handles scaling/caching (using LFU strategy) for optimized delivery.  
module name: Auth Service, module description: Handles user and session authentication, hashes passwords using BCrypt, and validates sessions via salted SHA512 hashing to prevent tampering.  
module name: Persistence Service, module description: Manages access to the relational database, maps entities to JSON objects using JPA ORM, and provides CRUD operations. Acts as a caching layer via JPA's second-level cache.  
module name: Recommender Service, module description: Generates personalized product recommendations using Slope One (item-based collaborative filtering) or fallback popularity-based algorithms. Supports CPU/memory-intensive variants and an order-based nearest-neighbor approach.  
module name: Registry, module description: Tracks online service instances and their locations via registration/heartbeat signals. Assumes services are offline after 10s of missed heartbeats. Ensures single-instance simplicity for test environments.
