module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, and manages cookies. It also includes a status page displaying service instance information.  
module name: Image Provider, module description: Delivers images to the WebUI as base64-encoded strings, matches product IDs or UI names to image identifiers, and handles caching with an LFU strategy. Falls back to a "not found" image or resizes images if needed.  
module name: Auth Service, module description: Handles user and session authentication, hashes passwords using BCrypt, and validates session integrity using salted SHA512 hashes stored in cookies.  
module name: Persistence Service, module description: Provides CRUD operations for relational database entities, maps relational data to JSON objects using EclipseLink JPA, and includes a second-level entity cache for performance.  
module name: Recommender Service, module description: Generates personalized product recommendations based on user behavior (shopping cart, orders, or viewed items). Uses Slope One collaborative filtering or fallback popularity-based algorithms, with CPU- and memory-intensive variants.  
module name: Registry, module description: Tracks service instances, their locations, and availability via heartbeat signals. Ensures single-registry configuration for simplified multi-instance TeaStore deployments.
