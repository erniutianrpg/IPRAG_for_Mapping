module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, and manages cookie logic. Also includes a status page displaying service instance information.  
module name: Image Provider, module description: Delivers images as base64-encoded strings to the WebUI, matches product IDs or UI names to image identifiers, and handles image scaling/caching with an in-memory LFU cache.  
module name: Auth Service, module description: Handles user authentication and session validation using BCrypt for passwords and SHA512 for salted session hashes stored in cookies.  
module name: Persistence Service, module description: Manages access to the relational database, maps entities to JSON objects using EclipseLink JPA, and provides CRUD operations. Includes a second-level entity cache.  
module name: Recommender Service, module description: Generates personalized product recommendations using Slope One (item-based collaborative filtering) or order-based nearest-neighbor algorithms, with fallback to general popularity for unknown users.  
module name: Registry, module description: Tracks service instances, their locations, and online status via heartbeats. Ensures single-registry configuration for simplified multi-instance TeaStore setups.
