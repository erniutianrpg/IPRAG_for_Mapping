module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, manages cookies, and displays a status page with service instance information.  
module name: Image Provider, module description: Delivers base64-encoded images to the WebUI, matches product IDs or UI names to image identifiers, handles image scaling and caching, and returns a "not found" image if requested resources are unavailable.  
module name: Auth Service, module description: Handles user authentication and session validation, hashes passwords using BCrypt, and verifies session integrity using salted SHA512 hashes stored in cookies.  
module name: Persistence Service, module description: Manages access to the relational database, performs CRUD operations, maps relational entities to JSON objects using EclipseLink JPA, and acts as a caching layer via JPA's second-level cache.  
module name: Recommender Service, module description: Generates personalized product recommendations using Slope One collaborative filtering or fallback popularity-based algorithms, trained on user orders and shopping cart data, with CPU- and memory-intensive variants.  
module name: Registry, module description: Tracks service instances, their locations, and online status via heartbeat signals, enabling dynamic service discovery and configuration for the TeaStore ecosystem.
