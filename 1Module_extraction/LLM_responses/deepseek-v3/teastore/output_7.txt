module name: WebUI, module description: Provides the TeaStore front-end using Servlets and JSP files, handles user interactions, retrieves images from the Image Provider, and manages cookie logic. It also displays a status page showing the current state of the TeaStore and registered service instances.  
module name: Image Provider, module description: Delivers images to the WebUI as base64-encoded strings, matches product IDs or UI names to unique image identifiers, and handles image scaling and caching using an in-memory LFU strategy.  
module name: Auth Service, module description: Handles user and session authentication, hashes passwords using BCrypt, and validates session integrity using salted SHA512 hashes stored in cookies.  
module name: Persistence Service, module description: Provides CRUD operations for persistent entities, maps relational database data to JSON objects using EclipseLink JPA, and acts as a caching layer via JPA's second-level cache.  
module name: Recommender Service, module description: Generates personalized product recommendations based on user behavior (shopping cart, orders, and item views), using Slope One collaborative filtering or fallback popularity-based algorithms. Implements CPU-intensive and memory-intensive variants.  
module name: Registry, module description: Tracks online service instances and their locations, manages service registration and heartbeat signals, and ensures services are marked offline if heartbeats are missed. Supports single-instance configuration for simplicity.
