module name: model, module description: Represents core data structures (BibDatases, BibEntries, Events) with minimal attached logic; has no dependencies on other modules.  
module name: logic, module description: Handles reading/writing/importing/exporting and manipulating the model; structured as an API for the GUI; depends only on the model.  
module name: gui, module description: Outer layer responsible for user interaction, preferences, and task-solving; depends on logic and model.  
module name: cli, module description: Bundles classes for JabRef's command-line interface functionality.  
module name: preferences, module description: Manages user-customizable settings and personal configurations.  
module name: event bus, module description: Facilitates event publishing from the model to other layers to enable reactive architecture.
