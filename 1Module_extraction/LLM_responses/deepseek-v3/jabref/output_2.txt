module name: model, module description: Represents core data structures (e.g., BibDatabases, BibEntries, Events) with minimal attached logic; has no dependencies on other modules.  
module name: logic, module description: Handles reading/writing/importing/exporting and manipulating the model; acts as an API for the GUI and depends only on the model.  
module name: gui, module description: Manages user interaction, preferences, and task execution; depends on logic and model.  
module name: cli, module description: Provides command-line interface functionality for JabRef.  
module name: preferences, module description: Stores and manages user-customizable settings.  
module name: event bus, module description: Facilitates communication by publishing model events to other layers (e.g., logic, GUI).
