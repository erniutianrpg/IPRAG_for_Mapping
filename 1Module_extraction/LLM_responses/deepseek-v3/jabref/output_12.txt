module name: model  
module description: Represents core data structures (e.g., BibDatabases, BibEntries, Events) with minimal attached logic; has no dependencies on other modules.  

module name: logic  
module description: Handles reading, writing, importing, exporting, and manipulating the model; acts as an API for the GUI and depends only on the model.  

module name: gui  
module description: Provides the user interface, interacts with the user, and manages user preferences; depends on logic and model.  

module name: cli  
module description: Implements the command-line interface for JabRef.  

module name: preferences  
module description: Manages user-customizable settings and personal configurations.  

module name: event bus  
module description: Facilitates communication by publishing events from the model to other layers (e.g., logic, GUI).  

module name: testing (JUnit)  
module description: Enforces dependency rules (e.g., between model, logic, and GUI) and fails builds on violations.
