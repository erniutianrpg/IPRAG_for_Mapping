module name: model, module description: Represents core data structures (e.g., BibDatases, BibEntries, Events) with minimal attached logic; has no dependencies on other modules.  
module name: logic, module description: Handles reading, writing, importing, exporting, and manipulating the model; acts as an API for the GUI and depends only on the model.  
module name: gui, module description: Provides the user interface, interacts with the user, and manages user preferences; depends on logic and model.  
module name: cli, module description: Bundles classes responsible for the command-line interface functionality.  
module name: preferences, module description: Manages user-customizable settings and personal configurations.  
module name: event bus, module description: Facilitates event publishing from the model to other layers to enable reactive updates without violating architectural constraints.
