module name: model, module description: Represents core data structures (e.g., BibDatases, BibEntries, Events) with minimal attached logic; has no dependencies on other modules.  
module name: logic, module description: Handles reading, writing, importing, exporting, and manipulating the model; acts as an API for the GUI and depends only on the model.  
module name: gui, module description: Manages user interaction, preferences, and task-solving; depends on logic and model but has no inward dependencies.  
module name: cli, module description: Provides functionality for the command-line interface; operates independently or with minimal dependencies.  
module name: preferences, module description: Stores and manages user-customizable settings for personalization.  
module name: event bus, module description: Facilitates event publishing from the model to other layers to enable reactive architecture without direct dependencies.
