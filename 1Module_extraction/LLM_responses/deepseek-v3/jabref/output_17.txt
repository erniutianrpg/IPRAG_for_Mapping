module name: model  
module description: Represents core data structures (e.g., BibDatabases, BibEntries, Events) with minimal attached logic; has no dependencies on other modules.  

module name: logic  
module description: Handles reading, writing, importing, exporting, and manipulating the model; acts as an API for the GUI and depends only on the model.  

module name: gui  
module description: Provides the user interface, interacts with the user, and manages user preferences; depends on the logic layer.  

module name: cli  
module description: Implements the command-line interface for JabRef; functionally distinct from the GUI.  

module name: preferences  
module description: Manages user-customizable settings and personal configurations.  

module name: event bus  
module description: Facilitates communication by publishing model events to other layers (e.g., logic, GUI) without direct dependencies.  

module name: testing (JUnit)  
module description: Enforces architectural constraints (e.g., dependency rules between model, logic, GUI) via automated build failures.
