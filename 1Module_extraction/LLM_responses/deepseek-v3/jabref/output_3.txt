module name: model, module description: Represents core data structures (e.g., BibDatases, BibEntries, Events) with minimal attached logic; has no dependencies on other modules.  
module name: logic, module description: Handles reading, writing, importing, exporting, and manipulating the model; acts as an API for the GUI and depends only on the model.  
module name: gui, module description: Manages user interaction, preferences, and task-solving; depends on logic and model.  
module name: cli, module description: Provides functionality for the command-line interface.  
module name: preferences, module description: Stores user-customizable settings for personal needs.  
module name: event bus, module description: Facilitates event publishing from the model to other layers to enable reactive updates.
