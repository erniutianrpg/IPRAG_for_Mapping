module name: Redis PubSub, module description: A messaging system enabling communication between BigBlueButton components (e.g., HTML5 Server, akka-apps) via publish-subscribe channels, ensuring real-time event propagation.

module name: Redis DB, module description: Stores recorded meeting events for post-processing by the Recording Processor. Acts as a transient data store before final recording generation.

module name: Apps Akka, module description: The core real-time collaboration application, managing meeting logic (via MeetingActor), user lists, chat, whiteboard, and presentations. Processes messages for meetings and integrates with other services.

module name: FSESL Akka, module description: A standalone component integrating with FreeSWITCH via Event Socket Layer (ESL), handling voice conferencing and bridging communication between FreeSWITCH and other apps via Redis PubSub.

module name: FreeSWITCH, module description: Provides voice conferencing capabilities, supporting WebRTC (for browsers) and PSTN/VOIP integrations. Handles audio streams and call-in functionality.

module name: Kurento (WebRTC-SFU), module description: A media server (Kurento Media Server) acting as a WebRTC Selective Forwarding Unit (SFU), managing webcam streams, listen-only audio, and screensharing. Negotiates media streams for clients.

module name: Presentation Conversion Service, module description: Converts uploaded Office documents to PDF (via LibreOffice) and then to SVG/PNG (via bbb-web) for display in the client. Manages fallback workflows for performance optimization.

module name: Recording Processor, module description: Processes raw meeting events (from Redis DB) and media files (PDF, WAV, FLV) to generate finalized recordings after a meeting ends.

module name: Nginx, module description: Acts as a reverse proxy and load balancer, handling SSL termination, WebSocket connections, and routing traffic between the HTML5 Client and HTML5 Server.
