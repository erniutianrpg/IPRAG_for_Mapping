module name: HTML5 Client, module description: A responsive web application built with React.js and WebRTC, handling user interface rendering, audio/video communication, and real-time state synchronization with the server via WebSocket and MiniMongo.

module name: HTML5 Server, module description: A Meteor.js-based server managing client-server communication, state consistency via MongoDB, and scalable message processing through distributed Node.js processes (frontend/backend roles).

module name: MongoDB, module description: Database storing meeting and client state information, with data automatically synchronized between server and clients via subscriptions/publications.

module name: BBB Web (Scala Application), module description: Java/Scala-based web application implementing the BigBlueButton API for third-party integrations (e.g., Moodle, Greenlight) and managing meeting state.

module name: Redis PubSub, module description: Communication channel for real-time messaging between BigBlueButton components (e.g., HTML5 server, akka-apps).

module name: Redis DB, module description: Temporary storage for meeting events during sessions, later processed by the Recording Processor for recordings.

module name: Apps Akka, module description: Core application orchestrating real-time collaboration features (users, chat, whiteboard) via the MeetingActor, which processes meeting logic and messages.

module name: FSESL Akka, module description: Dedicated component integrating FreeSWITCH for voice conferencing, communicating with other services via Redis PubSub.

module name: FreeSWITCH, module description: Voice conferencing system supporting WebRTC (high-quality audio) and PSTN/VOIP call-ins, managed by FSESL Akka.

module name: Kurento (WebRTC-SFU), module description: Media server handling webcam streams, screensharing, and listen-only audio, with WebRTC-SFU managing stream negotiations.

module name: Presentation Conversion Service, module description: Converts uploaded documents (Office/PDF) to SVG/PNG via LibreOffice and bbb-web, with fallback logic for browser performance.

module name: Recording Processor, module description: Processes meeting events (from Redis DB) and raw media files (PDF, WAV, FLV) to generate recordings post-meeting.

module name: Nginx, module description: Reverse proxy handling SSL termination, WebSocket connections, and routing traffic between clients and the HTML5 server. 

(Note: Merged "frontend/backend" processes under HTML5 Server for scalability, and grouped related components like Kurento/WebRTC-SFU.)
