module name: HTML5 Client, module description: A responsive single-page web application built with React.js and WebRTC, handling user interface rendering, audio/video communication, and real-time updates via WebSocket connections to the server. It interacts with the HTML5 Server and maintains client-state consistency using MiniMongo.

module name: HTML5 Server, module description: A Meteor.js-based server component that manages client-server communication, state synchronization via MongoDB, and scalable message processing across multiple Node.js processes (frontend/backend roles). Frontends handle authentication and streamer events, while backends manage non-streamer events and load balancing.

module name: BBB Web, module description: A Scala/Java-based web application implementing the BigBlueButton API for third-party integrations (e.g., Moodle, Greenlight). It holds meeting state and serves as the primary entry point for external control of the server.

module name: Redis PubSub, module description: A communication channel for real-time messaging between BigBlueButton components (e.g., HTML5 Server, akka-apps) and event distribution during meetings.

module name: Redis DB, module description: Stores meeting events for recording purposes; processed by the Recording Processor post-meeting to generate final recordings from raw data (PDF, WAV, FLV).

module name: Apps Akka, module description: The core real-time collaboration application managing meeting logic (via MeetingActor), user lists, chat, whiteboard, and presentations. Coordinates with other services via Redis PubSub.

module name: FSESL Akka, module description: A standalone component integrating with FreeSWITCH for voice conferencing, using Redis PubSub for communication with other services. Designed for extensibility with alternative voice systems.

module name: FreeSWITCH, module description: Handles voice conferencing, supporting WebRTC (high-quality audio) and PSTN/VOIP phone integrations. Central to audio functionality in meetings.

module name: Kurento (WebRTC-SFU), module description: Media server (Kurento Media Server) managing webcam streams, screensharing, and listen-only audio. Acts as a WebRTC Selective Forwarding Unit (SFU) for media negotiation and stream control.

module name: Presentation Conversion Service, module description: Converts uploaded Office documents to PDF (via LibreOffice) and then to SVG/PNG (via bbb-web) for display in the client. Includes fallback mechanisms for browser compatibility and performance optimization.

module name: Recording Processor, module description: Processes raw meeting events (from Redis DB) and media files post-meeting to generate finalized recordings.

module name: Nginx, module description: Reverse proxy handling SSL termination, WebSocket routing, and load balancing for client-server connections (e.g., HTML5 Client to HTML5 Server).
