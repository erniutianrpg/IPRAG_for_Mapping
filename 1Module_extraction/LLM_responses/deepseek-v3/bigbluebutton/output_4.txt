module name: HTML5 Client, module description: A responsive web application built with React.js and WebRTC, handling user interface rendering, audio/video communication, and real-time state synchronization with the server via WebSocket and MiniMongo.  

module name: HTML5 Server, module description: A Meteor.js-based server managing client-server communication, state consistency via MongoDB, and scalable message processing across multiple Node.js processes (frontend/backend roles).  

module name: BBB Web, module description: A Scala/Java application implementing the BigBlueButton API for third-party integrations (e.g., Moodle), managing meeting states, and handling presentation conversions (PDF to SVG).  

module name: Redis PubSub, module description: A messaging channel enabling real-time communication between BigBlueButton components (e.g., HTML5 Server, akka-apps) and storing meeting events for recordings.  

module name: Apps Akka, module description: The core application orchestrating real-time collaboration features (users, chat, whiteboard) and processing meeting logic via the MeetingActor.  

module name: FSESL Akka, module description: A standalone component integrating with FreeSWITCH for voice conferencing, using Redis PubSub for communication with other services.  

module name: FreeSWITCH, module description: The voice conferencing system supporting WebRTC (high-quality audio) and PSTN/VOIP call-ins for users.  

module name: Kurento (WebRTC-SFU), module description: A media server (SFU/MCU) handling webcam streams, screensharing, and listen-only audio, managed by the WebRTC-SFU controller.  

module name: Recording Processor, module description: Processes recorded meeting events (from Redis) and raw media files (PDF, WAV, FLV) to generate finalized recordings.  

module name: Presentation Converter, module description: Converts uploaded Office documents to PDF (via LibreOffice) and PDF to SVG (with fallbacks for browser optimization).  

module name: nginx, module description: A reverse proxy handling SSL/TLS termination, WebSocket routing, and load balancing for client-server connections.  

module name: MongoDB, module description: The primary database storing meeting metadata, user states, and chat messages, synchronized with client-side MiniMongo.  

(Note: Redundant terms like "HTML5 server component" were merged into "HTML5 Server," and "BBB web" was standardized to "BBB Web.")
