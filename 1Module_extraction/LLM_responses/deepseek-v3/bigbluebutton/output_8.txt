Here¡¯s the extracted and consolidated list of architecture modules with their responsibilities:

1. **module name**: HTML5 Client  
   **module description**: A responsive single-page web application built with React.js and WebRTC, handling user interface rendering, audio/video communication, and real-time updates via WebSocket connections to the server. Uses MiniMongo for client-side state synchronization with the server.

2. **module name**: HTML5 Server  
   **module description**: A Meteor.js-based server managing client-server communication and state consistency via MongoDB. Scalable across multiple Node.js processes (frontend/backend roles) to distribute load (e.g., authentication, event handling, and Redis streamer events).

3. **module name**: MongoDB  
   **module description**: Central database storing meeting states, user data, and chat messages. Synchronizes with client-side MiniMongo via server-side subscriptions/publications.

4. **module name**: BBB Web (API Server)  
   **module description**: A Scala/Java application implementing the BigBlueButton API for third-party integrations (e.g., Moodle, Greenlight). Manages meeting state and provides endpoints for server control.

5. **module name**: Redis PubSub  
   **module description**: Facilitates real-time messaging between components (e.g., HTML5 Server, Akka Apps, FreeSWITCH) via publish-subscribe channels.

6. **module name**: Redis DB  
   **module description**: Stores meeting events for recording processing. Archived events and raw files are processed post-meeting by the Recording Processor.

7. **module name**: Apps Akka  
   **module description**: Core application for real-time meeting collaboration (users, chat, whiteboard, presentations). Uses MeetingActor for meeting logic and event processing.

8. **module name**: FSESL Akka  
   **module description**: Dedicated component integrating FreeSWITCH via Event Socket Layer (ESL), enabling voice conferencing. Communicates with Apps Akka via Redis PubSub.

9. **module name**: FreeSWITCH  
   **module description**: Handles voice conferencing, supporting WebRTC (high-quality audio) and PSTN/VOIP call-ins. Integrates with FSESL Akka for event management.

10. **module name**: Kurento Media Server (WebRTC-SFU)  
    **module description**: Manages media streaming (webcams, screensharing, listen-only audio) using WebRTC. Acts as a media controller for stream negotiation and management.

11. **module name**: Presentation Converter  
    **module description**: Converts uploaded Office documents to PDF (via LibreOffice) and then to SVG/PNG for client display. Uses Redis PubSub for progress updates and fallback mechanisms for browser performance.

12. **module name**: Nginx  
    **module description**: Reverse proxy handling SSL/TLS termination, WebSocket routing, and load balancing for client-server connections.

13. **module name**: Recording Processor  
    **module description**: Processes recorded meeting events (from Redis DB) and raw media files (PDF, WAV, FLV) into finalized recordings post-meeting.  

*(Note: Semantically similar components like frontend/backend Node.js processes were merged under HTML5 Server, and FreeSWITCH/FSESL Akka were separated for clarity.)*
