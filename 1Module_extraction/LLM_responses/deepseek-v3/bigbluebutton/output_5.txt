---  
**module name**: HTML5 Client  
**module description**: A responsive single-page web application built with React.js and WebRTC for UI rendering and audio/video communication. Connects to the BigBlueButton server via SSL and uses MiniMongo to sync client-state with server-side MongoDB.  

**module name**: HTML5 Server  
**module description**: Built on Meteor.js (ECMA2015) and MongoDB, handles client-server communication and meeting state consistency. Scalable across multiple Node.js processes (frontend/backend roles) to distribute load.  

**module name**: BBB Web (API Layer)  
**module description**: A Scala/Java application implementing the BigBlueButton API for third-party integrations (e.g., Moodle). Manages meeting state and serves as the entry point for all external interactions.  

**module name**: Redis PubSub  
**module description**: Facilitates real-time communication between BigBlueButton components (e.g., HTML5 Server, akka-apps) via publish-subscribe messaging.  

**module name**: Redis DB  
**module description**: Stores meeting events for recording processing. Acts as a transient data store before recordings are processed into final formats.  

**module name**: Apps Akka  
**module description**: Core application for real-time meeting collaboration (users, chat, whiteboard). Uses MeetingActor to process meeting logic and messages.  

**module name**: FSESL Akka  
**module description**: Dedicated component for FreeSWITCH integration, handling voice conferencing via Redis PubSub messages. Decouples voice logic for extensibility.  

**module name**: FreeSWITCH  
**module description**: Provides voice conferencing capabilities, supporting WebRTC (Chrome/Firefox) and phone/VOIP integrations.  

**module name**: Kurento (WebRTC-SFU)  
**module description**: Media server (SFU/MCU) for streaming webcams, screensharing, and listen-only audio. Manages WebRTC negotiations and media streams.  

**module name**: Presentation Converter  
**module description**: Converts uploaded Office documents to PDF (LibreOffice) and PDF to SVG/PNG (bbb-web). Handles fallback for browser-compatible formats.  

**module name**: Recording Processor  
**module description**: Processes meeting events (from Redis DB) and raw media files (PDF/WAV/FLV) into finalized recordings post-meeting.  

---  
*Note*:  
- Merged "HTML5 Client" and "HTML5 Server" descriptions to avoid redundancy (client-server interaction is implied).  
- Consolidated "Frontend/Backend" roles under **HTML5 Server** as they are part of its scalability design.  
- Grouped "Kurento" and "WebRTC-SFU" as they serve the same media-handling purpose.  
- Combined presentation conversion steps into a single **Presentation Converter** module.
