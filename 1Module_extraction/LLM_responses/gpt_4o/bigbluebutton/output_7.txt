
module name: HTML5 Client  
module description: The HTML5 Client is a responsive single-page web application built using React.js for UI rendering and WebRTC for handling audio and video communication. It connects directly to the BigBlueButton server for real-time user interaction and communication management.

module name: HTML5 Server  
module description: Constructed with Meteor.js, the HTML5 Server manages communication between the client and server, and uses MongoDB for data persistence and maintaining the state of each client and meeting. It facilitates scalability through the handling of frontend and backend processes.

module name: BigBlueButton Web (bbb-web)  
module description: A Java-based application written in Scala that implements BigBlueButton API, managing meeting states and providing integration with third-party applications. It serves as a portal for all access to BigBlueButton services and performs tasks like presentation conversion and meeting state management.

module name: Redis PubSub  
module description: Facilitates inter-application communication within the BigBlueButton server by providing a publish-subscribe messaging mechanism used by various modules.

module name: Redis DB  
module description: Stores all event data for meetings and supports the recording process by housing raw files (PDF, WAV, FLV) which are used during post-meeting processing.

module name: Apps Akka  
module description: The main application orchestrating various real-time collaboration features within meetings, including user management, chat, whiteboard and presentation sharing. It uses the meeting business logic contained in the MeetingActor component.

module name: FSESL Akka  
module description: Integrates BigBlueButton with FreeSWITCH by managing communication via Redis PubSub, simplifying the process for users to implement integrations with other voice conferencing systems.

module name: FreeSWITCH  
module description: Handles voice conferencing for BigBlueButton, offering users a high-quality audio connection through WebRTC or phone integration with VOIP providers.

module name: Kurento and WebRTC-SFU  
module description: Provides the media server capabilities needed for streaming webcams, managing listen-only audio, and screensharing through Kurento Media Server, with WebRTC-SFU acting as the media controller.

module name: Presentation Conversion Flow  
module description: Manages the process of converting presentations into formats suitable for web display (PDF to SVG) with fallback options to optimize performance and browser compatibility.
