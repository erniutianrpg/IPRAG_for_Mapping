module name: HTML5 Client
module description: A single page, responsive web application using React.js for rendering the user interface and WebRTC for audio/video communication. It connects with the BigBlueButton server via SSL over port 443 and handles communications through nginx.

module name: HTML5 Server
module description: Built on Meteor.js for server-client communication and MongoDB for maintaining consistent meeting state. Manages communication subscriptions and publishing to client-side MiniMongo.

module name: Scalability Component
module description: Enhances scalability by using multiple Node.js processes to handle messages and browser sessions, allowing use of multiple CPU cores. Configurable front-end and back-end roles manage specific event processes.

module name: BBB Web
module description: A Java-based application in Scala implementing the BigBlueButton API for third-party integrations, such as Moodle. Manages meeting state and serves as a central API endpoint for control.

module name: Redis PubSub
module description: Facilitates communication channels and message passing between BigBlueButton server applications. Key for event storage during meetings.

module name: Redis DB
module description: Stores all recorded meeting events for processing, including raw files like PDF, WAV, FLV.

module name: BigBlueButton Apps Akka
module description: Central application for real-time collaboration, managing user lists, chat, whiteboard, and presentations. Contains meeting business logic within MeetingActor to process meeting-specific messages.

module name: FSESL Akka
module description: Provides integration with FreeSWITCH for voice conferencing and enables easy integration with other conferencing systems using FreeSWITCH Event Socket Layer through Redis pubsub.

module name: FreeSWITCH
module description: Handles audio for voice conferencing, allowing connections via headset, phone, and WebRTC for high-quality audio.

module name: Kurento and WebRTC-SFU
module description: Kurento Media Server managing webcams, audio, and screensharing using SFU and MCU models. The WebRTC-SFU acts as a media controller for stream negotiation and management.

module name: Presentation Conversion Process
module description: Converts uploaded presentations (Office documents to PDF, then to SVG) for client display, handling progress messages via Redis pubsub. Includes fallback to rasterized image in SVG for browser optimization.
