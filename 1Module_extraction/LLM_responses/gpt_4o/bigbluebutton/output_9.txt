module name: HTML5 Client
module description: A responsive web application built using React.js and WebRTC, responsible for rendering the user interface, sending/receiving audio and video, and directly connecting with the BigBlueButton server over port 443 (SSL).

module name: HTML5 Server
module description: Built on Meteor.js and MongoDB, sitting behind nginx, it facilitates communication between the client and server, maintains meeting state consistency, manages client subscriptions to server-published collections, and scales using multiple nodejs processes to handle incoming messages.

module name: Frontend Processes
module description: Handles authentication events, collection subscription and publishing, DDP events, and Streamer redis events such as annotations, external video share, and manages event processing queues for meetings.

module name: Backend Processes
module description: Responsible for processing non-streamer redis events and balances load using round-robin distribution across multiple backend instances, processing events relevant to specific meetings.

module name: BBB Web
module description: A Java-based application written in Scala implementing the BigBlueButton API, facilitating third-party integrations, managing meeting state, and supporting front-end portals for connecting users to meeting rooms.

module name: Redis PubSub
module description: Provides a communication channel between various applications on the BigBlueButton server, facilitating message exchange and synchronization across components.

module name: Redis DB
module description: Stores recorded meeting events and files like PDFs, WAV, and FLV, supporting the Recording Processor in processing these recorded artifacts.

module name: Apps Akka
module description: The main application ensuring real-time collaboration in meetings, managing users, chat, whiteboard, and presentations, with meeting logic handled by the MeetingActor.

module name: FSESL Akka
module description: Manages integration with FreeSWITCH using FreeSWITCH Event Socket Layer (fsels) and redis pubsub, enabling customized voice conferencing integration.

module name: FreeSWITCH
module description: Provides voice conferencing capabilities, supporting high-quality audio connections via WebRTC and VOIP integrations for users joining by phone.

module name: Kurento and WebRTC-SFU
module description: Kurento Media Server handles streaming webcams, audio, and screensharing, while WebRTC-SFU manages media stream negotiations and control.

module name: Presentation Conversion
module description: Converts uploaded presentations into PDF using LibreOffice and then into SVG for client display, using redis pubsub to send progress updates and fallback mechanisms for heavy SVG files.

module name: Internal Network Connections
module description: Describes how various BigBlueButton components communicate via internal network socket connections, ensuring integrated operation across modules.
