module name: HTML5 Client  
module description: A responsive web application built using React.js for rendering the user interface and WebRTC for audio/video communication. It connects directly with the BigBlueButton server over SSL and is responsible for user interface interactions.

module name: HTML5 Server  
module description: Built on Meteor.js and MongoDB, it manages communication between client and server, ensuring consistency of BigBlueButton state. It handles the state propagation for meetings, subscriptions, and publishes collections from server to client.

module name: BigBlueButton API  
module description: A Java-based Scala application providing a third-party integration endpoint for controlling the BigBlueButton server. It manages meeting state replication and API interactions with external LMS systems like Moodle, Wordpress, and Canvas.

module name: Redis PubSub  
module description: Provides a communication channel between BigBlueButton server applications, ensuring messaging coherence across components.

module name: Redis DB  
module description: Stores meeting events and facilitates recording processing post-meeting using various raw file formats.

module name: Apps Akka  
module description: The main application bringing together diverse collaboration functionalities such as chat, whiteboard, and presentations within a meeting context. It manages meeting business logic through MeetingActor for message processing.

module name: FreeSWITCH Integration  
module description: Integrates FreeSWITCH for voice conferencing capabilities, enabling users to join audio sessions via WebRTC for higher quality audio or through phone using VoIP providers.

module name: Kurento and WebRTC-SFU  
module description: Manages streaming of media like webcams, screensharing, and audio by implementing SFU and MCU models. WebRTC-SFU handles media stream negotiation as the media controller.

module name: Presentation Conversion Process  
module description: Converts uploaded Office documents to PDF using LibreOffice, then to SVG for display within the client. Handles fallback mechanisms for efficient SVG loading in browsers.

module name: Internal Network Connections  
module description: Manages socket-based communication between BigBlueButton components ensuring seamless inter-module connectivity.
