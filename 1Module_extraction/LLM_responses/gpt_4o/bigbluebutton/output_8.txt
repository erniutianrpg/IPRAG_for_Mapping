module name: HTML5 Client  
module description: A single-page, responsive web application that provides the user interface for BigBlueButton. Utilizes React.js for rendering, and WebRTC for audio and video communication, connecting directly to the BigBlueButton server via HTTPS.

module name: HTML5 Server  
module description: Built on Meteor.js for client-server communication and MongoDB for state management, it ensures consistent meeting states across BigBlueButton clients. It functions behind nginx and supports scalability through multiple nodejs processes for handling client communications.

module name: Nginx  
module description: Acts as a reverse proxy, handling web socket connections between the HTML5 client and server.

module name: Node.js Processes  
module description: Handles incoming client messages using multiple CPU cores to improve scalability and processing efficiency, with distinct frontend and backend processes for managing various events.

module name: BBB Web  
module description: A Java-based application implemented in Scala responsible for managing BigBlueButton server API functionalities and facilitating third-party integrations. It provides portals for accessing and recording meetings through integrations like Moodle and Greenlight.

module name: Redis PubSub  
module description: Used as a communication channel between different BigBlueButton applications, facilitating event storage and propagation.

module name: Redis DB  
module description: Stores meeting events for recording purposes, processed post-meeting by the Recording Processor into different formats.

module name: Apps Akka  
module description: Central application facilitating real-time collaboration within meetings, handling user lists, chats, whiteboards, and presentations, with business logic encapsulated in MeetingActor.

module name: FSESL Akka  
module description: Manages integration with FreeSWITCH for audio conferencing, allowing flexibility for integration with other voice conference systems through Redis pubsub messaging.

module name: FreeSWITCH  
module description: Provides voice conferencing capabilities, integrating with WebRTC for high-quality audio and supporting phone call-ins through VOIP providers.

module name: Kurento Media Server (KMS) and WebRTC-SFU  
module description: Manages media streaming (webcams, audio, screensharing) with SFU and MCU models, controlling media negotiations and stream management.

module name: Presentation Conversion  
module description: Converts uploaded presentations into PDFs and SVGs for display within the client, ensuring efficient rendering through a fallback mechanism that uses rasterized images as needed.

module name: Internal Network Connections  
module description: Handles communication across various BigBlueButton components through network sockets, supporting the overall system integration.
