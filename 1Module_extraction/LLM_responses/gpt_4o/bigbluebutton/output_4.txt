2. **HTML5 Server**:  
   **Description**: Built on Meteor.js for client-server communication and MongoDB to maintain meeting data synchronization, it scales by using multiple Node.js processes to handle frontend and backend operations separately.

3. **BBB Web**:  
   **Description**: A Java-based application written in Scala that implements the BigBlueButton API, enabling integration with third-party applications and managing meeting states.

4. **Redis PubSub**:  
   **Description**: Provides a messaging channel for communication between different BigBlueButton applications.

5. **Redis DB**:  
   **Description**: Stores meeting events for recordings, later processed by the Recording Processor along with associated media files.

6. **Apps Akka**:  
   **Description**: Manages real-time collaboration features like user management, chat, whiteboard, and presentations within a meeting, with core business logic residing in the MeetingActor component.

7. **FSESL Akka**:  
   **Description**: Integrates with FreeSWITCH for voice conferencing, leveraging Redis PubSub for communication.

8. **FreeSWITCH**:  
   **Description**: Provides audio conferencing capabilities, supporting high-quality WebRTC connections and integration with VOIP providers for telephony.

9. **Kurento and WebRTC-SFU**:  
   **Description**: Kurento Media Server acts as a streaming server for webcams, audio, and screensharing, while the WebRTC-SFU manages media stream negotiations.

10. **Presentation Conversion**:  
    **Description**: Converts uploaded presentations into displayable formats, using LibreOffice for PDF conversion and further processes them into SVG or rasterized images for client display.
