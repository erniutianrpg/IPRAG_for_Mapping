module name: HTML5 Server
module description: The HTML5 Server is built on Meteor.js and MongoDB, facilitating communication between the client and server and maintaining a consistent state of meetings. It sits behind nginx and handles authentication, session management, and scales across multiple node.js processes.

module name: BBB Web
module description: BigBlueButton web application, written in Scala, implements the API for third-party integrations and copies meeting states. It works as a portal for handling client requests and integrates with learning management systems.

module description: BigBlueButton Apps uses Akka to integrate various components, providing real-time collaboration. It includes meeting logic through MeetingActor, handling user lists, chats, whiteboards, and presentations.

module name: FreeSWITCH
module description: Software for handling audio and voice conferencing in BigBlueButton, offering high-quality audio connections via WebRTC, and integrating with VOIP providers for phone access.

module name: Kurento and WebRTC-SFU

module name: Presentation Conversion Process
module description: Manages conversion of presentations, from document to PDF to scalable vector graphics (SVG), with fallback options for performance enhancement. Conversion messages are communicated via Redis PubSub.

module name: Redis PubSub
module description: Provides communication channels between different applications on the BigBlueButton server, supporting real-time messaging and updates among components.

module name: Redis DB
module description: Stores events and raw files from meetings for recording purposes, used by the Recording Processor to handle recorded data.
