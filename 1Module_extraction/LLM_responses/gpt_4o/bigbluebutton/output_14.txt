module name: HTML5 Client
module description: A single-page, responsive web application built using React.js and WebRTC for rendering the user interface and managing audio/video communication. It connects directly with the BigBlueButton server via SSL and interacts with the MongoDB database for client state consistency.

module name: HTML5 Server
module description: Built upon Meteor.js and MongoDB, it manages communication between the HTML5 client and server, maintaining and syncing the state of each client with the server. It also handles subscription and publication of collections related to meetings.

module name: HTML5 Scalability Component
module description: Handles scalability by distributing incoming client messages across multiple Node.js processes, separated into frontend and backend roles to efficiently process messages and manage browser sessions across multiple CPU cores.

module name: BBB Web
module description: A Java-based application implemented in Scala, providing the BigBlueButton API for third-party integration and managing a copy of the meeting state. It includes the Greenlight front-end and supports LMS integrations like Moodle and Canvas.

module name: Redis PubSub
module description: Acts as a communication channel between different applications on the BigBlueButton server, facilitating event recording and message passing through a publish-subscribe model.

module name: Apps Akka
module description: Coordinates real-time collaboration features such as user management, chat, whiteboard, and presentations within meetings. It contains the meeting business logic, processing and storing meeting-specific messages and information.

module name: FSESL Akka
module description: Manages integration with FreeSWITCH using Redis PubSub, allowing for seamless integration with other voice conference systems beyond FreeSWITCH.

module name: FreeSWITCH
module description: Provides audio handling and voice conferencing capabilities, supporting both WebRTC connections via browser and phone call-ins, and offering the potential for integration with VOIP providers.

module name: Kurento and WebRTC-SFU
module description: Kurento Media Server handles streaming of webcams, listen-only audio, and screensharing, while WebRTC-SFU manages media stream negotiation and control.

module name: Presentation Conversion
module description: Processes uploaded presentations by converting them to displayable formats (e.g., PDF to SVG), with a fallback mechanism to rasterize images for efficient browser loading. Uses Redis PubSub to send progress updates to the client.
