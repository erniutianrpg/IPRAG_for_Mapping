module name: UI Component  
module description: The UI Component is responsible for presenting the web application's interface to users. It consists of a single HTML page generated via the Angular framework with related HTML, CSS, and JavaScript files handled client-side. It processes user interactions, performs input validation, and facilitates asynchronous communication with the server through AJAX.

module name: UI Server  
module description: The UI Server acts as the entry point for the application¡¯s backend logic and is designed to follow RESTful principles. It manages HTTP requests, processes user-invoked and GAE server-invoked requests differently, and uses servlets like WebPageServlet and WebApiServlet to handle various functionalities.

module name: Logic Component  
module description: This component handles the business logic of TEAMMATES, including managing transaction atomicity, input sanitization, managing relationships between entities, and access control. It interfaces with both Google App Engine (GAE) and third-party APIs for additional operations like sending emails and queue management.

module name: Storage Component  
module description: Responsible for CRUD operations on data entities with a focus on interfacing with the GAE Datastore. It validates entity data, covers complexities related to data persistence, and performs data handling operations without executing cascade logic, which is managed by the Logic component.

module name: Common Component  
module description: Contains utility code shared across the application, including data transfer objects, helper classes, and custom exceptions. Its common.datatransfer package supports lightweight object transfer to simplify data exchange between components.

module name: Test Driver  
module description: Automates and manages various levels of testing within TEAMMATES using frameworks such as TestNG for Java and Jest for JavaScript. It provides infrastructure for running tests and includes specific test cases for components, integration, and system testing.

module name: E2E Component  
module description: Facilitates end-to-end (E2E) and load & performance (L&P) testing of the entire application as perceived by the end-user through Web browsers or REST API interactions. It contains utilities, page object abstractions, and specified test cases for full-system evaluation.

module name: Client Component  
module description: Allows for direct communication with the application¡¯s backend without a browser. Primarily used for administrative purposes, it supports tasks such as data migration and statistical analysis through specialized scripts and remote API connections.
