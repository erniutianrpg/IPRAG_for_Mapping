module name: UI Component  
module description: Manages the front-end interface of the application using Angular framework, rendering web pages, and handling client-side interactions such as input validation and AJAX requests.

module name: UI Server  
module description: Acts as the entry point for back-end logic using REST-ful controllers, processing HTTP requests and hand-off to appropriate servlets for further action.

module name: Logic Component  
module description: Handles business logic including entity management, transaction control, input sanitization, access control checks, and connecting to APIs.

module name: Storage Component  
module description: Responsible for performing CRUD operations, data validation, and interfacing with the GAE Datastore to hide persistence complexities from the logic component.

module name: Test Driver  
module description: Provides infrastructure and capabilities for automated testing, using frameworks like TestNG, Jest, and HttpUnit to ensure system reliability through component and integration tests.

module name: E2E Component  
module description: Facilitates end-to-end testing by interacting with the application via web browsers or REST API calls; also assists in load and performance tests.

module name: Client Component  
module description: Contains utility scripts for administratively interacting with the back-end, supporting tasks like data migration and statistics calculation.

module name: Common Component  
module description: Offers utility code including helper classes and data transfer objects that are used across various modules of the application.
