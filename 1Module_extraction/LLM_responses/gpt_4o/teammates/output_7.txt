module name: UI Component
module description: Responsible for presenting the user interface to users through web pages. It consists of HTML, CSS, and JavaScript files managed by the Angular framework. It handles client-side interactions, initiates HTTP requests to the server, and processes AJAX requests for dynamic data updates.

module name: UI Server (RESTful Controller)
module description: Acts as the entry point for application back-end logic. It processes requests via HTTP, forwards them to corresponding Servlets, and handles user-invoked and automated requests using REST principles.

module name: Logic Component
module description: Manages business logic, handles entity relationships, manages transactions, sanitizes input, checks access control, and connects to external APIs or GAE services. It is divided into logic.api for accessible APIs and logic.core for core business operations.

module name: Storage Component
module description: Responsible for CRUD operations and data validation using GAE Datastore. It abstracts persistence complexities from logic and provides Attributes as non-persistent data transfer objects.

module name: Common Component
module description: Contains utility code, data transfer objects, and custom exceptions shared across the application to streamline operations and data handling.

module name: Test Driver Component
module description: Facilitates automated regression testing using various test frameworks and strategies. It includes infrastructure for running tests, test cases, and sub-packages for different testing scopes and components.

module name: End-to-End (E2E) Component
module description: Performs comprehensive testing of the application¡¯s workflow, functionality, and performance through Web browser interactions or REST API calls. It includes utilities and page object abstractions for effective E2E testing.

module name: Client Component
module description: Provides scripts for direct connection to the back-end for administrative tasks, including data migration and statistical computations.
