module name: UI Browser  
module description: Responsible for rendering web pages using HTML, CSS, and JavaScript for client-side interactions. Built with Angular framework; handles initial page requests, AJAX data requests asynchronously, and is the user-visible interface of the application.

module name: UI Server  
module description: Functions as the backend entry point for application logic, designed as a RESTful controller using POJOs. It processes requests, applies custom filters, forward requests to servlets, and executes frontend-relevant actions.

module name: Logic  
module description: Handles the business logic of TEAMMATES, including entity relationship management, transaction management, input sanitization, and access control. Facilitates connections to APIs and manages components like GateKeeper, EmailGenerator, and TaskQueuer.

module name: Storage  
module description: Performs CRUD operations on data entities and contains the persistence logic using GAE Datastore. It validates data and hides complexities of datastore interactions, encapsulating entity data in non-persistent data transfer objects.

module name: Common  
module description: Contains utility code, custom exceptions, and data transfer objects used across the application. Provides common functionalities and helps in structured data transfer between components.

module name: Test Driver  
module description: Automates testing of the application with TestNG, Jest, and Selenium Java. Includes infrastructure for regression, unit, integration, and system tests along with specific tools for testing component functionalities.

module name: E2E  
module description: Facilitates end-to-end testing and load & performance tests by interacting with the web application as a whole, using Web browsers or REST APIs without knowledge of internal application workflows.

module name: Client  
module description: Provides scripts for administrative tasks directly interfacing with the application backend without a web browser. Used for data migration and statistical calculations, among other management activities.
