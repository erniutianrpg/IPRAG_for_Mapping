module name: UI Component  
module description: Responsible for client-side interactions, consisting of a single HTML page built using Angular framework with HTML, CSS, and JavaScript. It handles user interface interactions such as sorting and input validation, sending HTTP requests and AJAX requests to the server asynchronously.

module name: UI Server  
module description: Acts as the entry point for application back-end logic using a RESTful controller. It processes both user-invoked and automated requests using Servlet objects and applies custom filters for requests.

module name: Logic Component  
module description: Handles business logic such as managing entity relationships and transactions, sanitizing inputs, ensuring access control rights, and connecting to GAE-provided and third-party APIs. Uses a Template Method pattern for processing requests.

module name: Storage Component  
module description: Responsible for CRUD operations on data entities using the GAE Datastore, including data validation, and hiding datastore complexities from the Logic component. Contains storage.api, storage.entity, and storage.search packages.

module name: Test Driver  
module description: Facilitates automated regression testing using TestNG for Java and Jest for JavaScript unit-testing, as well as HttpUnit for simulated servlet-level tests. It includes component tests, integration tests, and separate front-end tests.

module name: E2E Component  
module description: Interacts with the application as a whole with web browsers for end-to-end (E2E) tests and load & performance (L&P) tests, using Selenium Java for browser automation.

module name: Client Component  
module description: Enables direct connection to the back end for administrative tasks like migrating data and calculating statistics without using a web browser. Includes client.util, client.remoteapi, and client.scripts packages.

module name: Common Component  
module description: Provides utility code including data transfer objects, helper classes, and custom exceptions used across the application. Includes common.util, common.exceptions, and common.datatransfer packages.
