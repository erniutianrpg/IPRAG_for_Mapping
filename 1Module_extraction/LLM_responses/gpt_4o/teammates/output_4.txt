module name: UI Component  
module description: The UI Component is the user interface of the application, implemented using the Angular framework and consisting of HTML, CSS, and JavaScript for client-side interactions. It handles the rendering of web pages, processing of AJAX requests, and client-side access control checks.

module name: Logic Component  
module description: The Logic Component manages the business logic of TEAMMATES, handling entity relationships, transactions, input sanitization, access control, and connecting to APIs for additional functionalities like task queue management and email sending.

module name: Storage Component  
module description: The Storage Component is responsible for CRUD operations on data entities, validating data before persistence, and encapsulating data persistence complexity from the Logic Component. It focuses on data validation, hiding data persistence complexities, and providing a flexible data schema.

module name: Common Component  
module description: The Common Component includes utility code such as data transfer objects and helper classes, used across the application to facilitate communication between components, error handling, and common utilities.

module name: Test Driver Component  
module description: The Test Driver Component automates regression testing of TEAMMATES, using frameworks like TestNG for Java and Jest for JavaScript testing. It includes test infrastructure and helpers.

module name: E2E Component  
module description: The E2E Component is used for end-to-end testing, interacting with the application through web browsers or REST API calls, and performing load and performance tests.

module name: Client Component  
module description: The Client Component comprises scripts that connect directly to the back-end for administrative tasks, such as data migration and statistics calculation, bypassing the standard web interface.

module name: Web API
module description: The Web API component processes HTTP requests made to the server. It includes REST-ful controllers for routing, action processing, and access control checks, distinguishing between user-invoked and automated/GAE-invoked requests.
