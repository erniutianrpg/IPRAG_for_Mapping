module name: WebUI  
module description: The WebUI module acts as the front-end of the TeaStore, responsible for retrieving images from the Image Provider, managing user interface components using Servlets and JSPs, handling cookie operations, and providing a status page that displays the current state of the TeaStore.  

module name: Image Provider  
module description: The Image Provider module delivers images as base64 encoded strings for embedding in HTML. It manages image retrieval by matching product IDs or UI names and image sizes, supplying standard images when unidentified, and caching images using an LFU strategy for quicker delivery.  

module name: Auth  
module description: The Auth module handles user and session authentication by hashing passwords with BCrypt and validating sessions with salted and hashed SessionBlobs stored in cookies.  

module name: Persistence Provider  
module description: The Persistence Provider module interacts with the relational database back-end, providing CRUD operations for persistent entities. It uses EclipseLink JPA for entity mapping and serves as a caching layer by utilizing a second-level JPA cache.  

module name: Recommender  
module description: The Recommender module generates personalized product recommendations based on user activity, utilizing order history and collaborative filtering. It supports two algorithmic versions: one CPU-intensive and one memory-intensive, along with an order-based nearest-neighbor approach.  

module name: Registry  
module description: The Registry module maintains a record of all service instances online, including their location. It requires services to self-register at startup and periodically re-register as a heartbeat mechanism to ensure availability. It supports the configuration of multiple TeaStore instances efficiently.
