module name: WebUI  
module description: The WebUI module is responsible for providing the TeaStore front-end using Servlets and JSP files. It manages user interactions, retrieves images from the Image Provider, handles authentication through the Auth service, manages cookies, and displays a status page indicating the current state of the TeaStore.

module name: Image Provider  
module description: The Image Provider module retrieves and delivers images to the WebUI as base64 encoded strings. It determines image availability and size, handles image scaling, implements an LFU in-memory cache for faster delivery, and retrieves images from a physical drive when necessary.

module name: Auth  
module description: The Auth module handles user and session authentication. It uses BCrypt for password hashing and applies SHA512 for salting and hashing the SessionBlob, storing it in cookies to validate sessions and prevent session tampering.

module name: PersistenceProvider  
module description: The PersistenceProvider module provides data access to the relational database back-end. It uses EclipseLink JPA for ORM mapping, supports CRUD operations, and serves as a caching layer through the JPA's second-level cache.

module name: Recommender  
module description: The Recommender module generates individual product recommendations based on users' shopping behavior. It applies various algorithms, including Slope One and an order-based nearest-neighbor approach, adapting the recommendation strategy based on user data availability.

module name: Registry  
module description: The Registry module manages the registration and heartbeat monitoring of service instances within the TeaStore. It provides information on the number and location of active service instances and assumes services to be offline if heartbeat signals are missed for a specified duration.
