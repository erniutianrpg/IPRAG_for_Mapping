module name: WebUI  
module description: The WebUI serves as the TeaStore front-end, utilizing Servlets and JSP files. It retrieves images from the Image Provider and handles cookie-based logic for saving and retrieving values. It also provides a status page displaying the current state of the TeaStore, including service instance counts and host information.

module name: Image Provider  
module description: The Image Provider is responsible for delivering base64 encoded images to the WebUI. It matches product IDs or UI names and image sizes to retrieve the correct image. It features an in-memory cache with a Least Frequently Used (LFU) replacement strategy to expedite image delivery.

module name: Auth Service  
module description: The Auth Service manages user and session authentication, implementing password hashing via BCrypt. It handles session validation by salting and hashing SessionBlobs using SHA512, checking for session tampering via cookie content verification.

module name: Persistence Provider  
module description: The Persistence Provider facilitates data access from a relational database back-end. It maps relational entities to JSON objects using EclipseLink JPA ORM and supports CRUD operations. It also functions as a caching layer through a second-level entity cache.

module name: Recommender  
module description: The Recommender generates personalized product recommendations using collaborative filtering techniques based on user activity, such as shopping carts and order history. It employs CPU-intensive and memory-intensive algorithms, including Slope One and order-based nearest-neighbor approaches.

module name: Registry  
module description: The Registry tracks online service instances, recording their locations and instance counts. Services self-register on startup and send periodic heartbeat signals to maintain their status as online. All TeaStore instances utilize a single registry for simplified configuration.
