module name: WebUI  
module description: The WebUI service provides the front-end for the TeaStore. It retrieves images from the Image Provider and handles user interactions through Servlets and JSP files. The WebUI is responsible for authenticating users via the Auth service, managing cookies, and presenting data from the PersistenceProvider and recommendations from the Recommender service. It also provides a status page indicating the state of the TeaStore.

module name: Image Provider  
module description: The Image Provider service delivers base64 encoded images to the WebUI for integration into HTML. It identifies images by product ID, UI name, and requested size, offering a scaled option if necessary. It employs an in-memory LFU cache for efficient image retrieval.

module name: Auth Service  
module description: The Auth service is responsible for user and session authentication. It utilizes BCrypt for password hashing and SHA512 for session validation by hashing and verifying the SessionBlob stored in cookies.

module name: Persistence Service  
module description: The Persistence service manages data storage and retrieval in a relational database back-end. It maps relational entities to JSON objects using EclipseLink JPA and provides CRUD operations with an integrated caching layer.

module name: Recommender Service  
module description: The Recommender service generates personalized product recommendations based on user interactions and past purchases using both collaborative filtering and nearest-neighbor algorithms. It handles both known and unknown users by applying different recommendation strategies.

module name: Registry  
module description: The Registry manages the status and location of service instances. Services register and periodically send heartbeats. It provides a centralized service configuration, enabling efficient management and monitoring of service instances within the TeaStore infrastructure.
