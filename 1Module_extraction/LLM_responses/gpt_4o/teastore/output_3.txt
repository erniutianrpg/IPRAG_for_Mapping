module name: WebUI  
module description: The WebUI module provides the TeaStore front-end and is responsible for rendering HTML pages using Servlets and JSP files. It retrieves images from the Image Provider and handles user interfaces, including a status page displaying the state of the TeaStore. It also manages cookie operations for saving and retrieving values.  

module name: Image Provider  
module description: The Image Provider delivers images to the WebUI as base64 encoded strings. It manages image retrieval based on product ID or UI name and image size, including caching with a Least Frequently Used (LFU) replacement strategy for quick access.  

module name: Auth Service  
module description: The Auth Service handles user and session authentication. It uses BCrypt to hash passwords and validates sessions by hashing the SessionBlob with SHA512. This module ensures secure session management through cookies. 

module name: PersistenceProvider  
module description: The PersistenceProvider provides access to the relational database, performing CRUD operations and converting relational entities to JSON entity objects. It employs EclipseLink JPA for ORM mapping and includes a second-level cache, acting as a caching layer. 

module name: Recommender  
module description: The Recommender module generates personalized product recommendations. It utilizes user shopping behavior by analyzing current carts, past orders, and item popularity. Techniques include Slope One collaborative filtering and nearest-neighbor approaches, with variants balancing CPU and memory usage.  

module name: Registry  
module description: The Registry tracks the number and location of online service instances. It requires service instances to register and send periodic heartbeats, managing their online status. It's crucial for the configuration and maintenance of running TeaStore instances.
