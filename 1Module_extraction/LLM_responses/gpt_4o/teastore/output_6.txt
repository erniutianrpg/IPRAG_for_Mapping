module name: WebUI  
module description: The WebUI service provides the TeaStore front-end using Servlets and JSP. It retrieves images from the Image Provider, authenticates users, handles cookies, and offers a status page showing service instance information.

module name: Auth  
module description: The Auth service handles user and session authentication. It uses BCrypt for password hashing and SHA512 for validating session integrity, storing session data in cookies.

module name: Image Provider  
module description: The Image Provider service delivers images to the WebUI in base64 encoded strings. It includes image matching, resizing, caching with a LFU strategy, and provides "not found" images if required identifiers are absent.

module name: PersistenceProvider  
module description: The Persistence service manages access to data in the relational database back-end. It uses EclipseLink JPA ORM for entity mapping and supports CRUD operations while serving as a caching layer with second-level caching.

module name: Recommender  
module description: The Recommender service generates personalized product recommendations based on user interactions, historical purchases, and item popularity using collaborative filtering and order-based nearest neighbor algorithms.

module name: Registry  
module description: The Registry monitors active instances of all services, requiring periodic heartbeat signals for availability checks. It facilitates easy configuration for multiple TeaStore instances with a centralized registry.
