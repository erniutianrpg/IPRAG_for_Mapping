module name: WebUI  
module description: Responsible for providing the TeaStore front-end utilizing Servlets and JSP files. It manages user interactions, retrieves images from the Image Provider, manages cookies, and provides a status page to display the current state of the TeaStore.

module name: Image Provider  
module description: Delivers images to the WebUI as base64 encoded strings, matching product IDs or UI names to image identifiers. Provides caching with LFU strategy to speed up image delivery, managing image storage and size scaling.

module name: Auth  
module description: Handles user authentication, including password hashing using BCrypt. Manages session authentication by salting and hashing SessionBlob with SHA512, storing results in cookies and checking for session tampering.

module name: PersistenceProvider  
module description: Provides data access to the persistent relational database, utilizing EclipseLink JPA ORM for mapping. Supports CRUD operations and acts as a caching layer using JPA implementation's second level cache.

module name: Recommender  
module description: Generates product recommendations for users based on their shopping cart, purchasing history, and item ratings. Utilizes collaborative filtering and various algorithms including Slope One and nearest-neighbor approaches.

module name: Registry  
module description: Keeps track of online service instances, their locations, and ensures services are registered and sending heartbeat signals to confirm activity. Manages service instance information for easy configuration of multiple TeaStores.
