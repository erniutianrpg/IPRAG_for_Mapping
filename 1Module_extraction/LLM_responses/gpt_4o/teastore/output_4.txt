module name: WebUI  
module description: The WebUI module serves as the front-end for the TeaStore, implemented using Servlets and JSPs. It manages user interactions, retrieves product images from the Image Provider, handles cookies for storing and retrieving values, and provides a status page showing the current state of service instances.

module name: Image Provider  
module description: The Image Provider module supplies images to the WebUI as base64 encoded strings. It matches product IDs or UI names and requested sizes to a unique image identifier, delivering either the existing image or a scaled version. It includes an in-memory cache with an LFU strategy to speed up image delivery.

module name: Auth  
module description: The Auth module is responsible for handling user and session authentication. It hashes passwords using BCrypt and validates sessions through a salted and hashed SessionBlob stored in cookies. It checks for session tampering by comparing the re-salted SessionBlob against the stored hash.

module name: PersistenceProvider  
module description: The PersistenceProvider module provides data access to a relational database backend. It maps relational entities to JSON objects using EclipseLink JPA, supports CRUD operations, and functions as a caching layer with a second-level entity cache.

module name: Recommender  
module description: The Recommender module generates personalized product recommendations based on user activity, such as current shopping cart contents, past purchases, and item popularity. It employs algorithms like Slope One for collaborative filtering and a nearest-neighbor approach for order-based recommendations.

module name: Registry  
module description: The Registry module maintains information on the number and location of service instances online. Services register and send periodic heartbeat signals to the Registry. It assumes services missing their heartbeat are offline until they re-register. The Registry supports single-instance configuration for the TeaStore test application.
