module name: WebUI  
module description: The WebUI module serves as the front-end for the TeaStore application. It employs Servlets and JSP files to display the user interface, manages cookies to save and retrieve values, and shows a status page displaying the state of the TeaStore. It retrieves images primarily from the Image Provider and is responsible for embedding base64 encoded images within the HTML.   

module name: Image Provider  
module description: The Image Provider module is responsible for delivering images to the WebUI. It retrieves images based on product ID or UI name and image size, and serves them as base64 encoded strings. It implements an in-memory cache with a Least Frequently Used (LFU) replacement strategy to speed up image retrieval.  

module name: Auth  
module description: The Auth module manages user and session authentication. It hashes passwords using BCrypt and secures sessions with a salted and hashed SessionBlob stored as a cookie. It validates received session cookies to prevent session tampering.  

module name: Persistence Provider  
module description: The Persistence Provider module offers access to relational database persisted data, facilitating CRUD operations for persistent entities. It maps relational data to JSON entities using the EclipseLink JPA ORM mapper and incorporates a caching layer via a JPA second-level cache.  

module name: Recommender  
module description: The Recommender module generates personalized product recommendations based on user history, current cart content, and product popularity. It employs Slope One collaborative filtering and nearest-neighbor approaches, offering CPU or memory-intensive recommendation calculations.  

module name: Registry  
module description: The Registry module tracks and provides information about online service instances, including their location. It ensures instances register and send periodic heartbeats to confirm activity, assuming offline status if heartbeats are missed.
