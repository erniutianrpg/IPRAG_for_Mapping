module name: WebUI  
module description: The WebUI service provides the TeaStore front-end using Servlets in combination with JSP files. It handles user interactions, retrieves images from the Image Provider service, manages cookies, and provides a status page indicating the current state of the TeaStore.

module name: Image Provider  
module description: The Image Provider service is responsible for delivering images as base64 encoded strings to the WebUI for embedding in the HTML. It uses caching to speed up delivery and scales images if the requested size is unavailable.

module name: Auth Service  
module description: The Auth service handles user and session authentication, including password hashing using BCrypt and session validation using salted and hashed SessionBlobs stored in cookies.

module name: Persistence Service  
module description: The Persistence service acts as a gateway to the relational database backend, providing CRUD operations for persistent entities. It maps relational data to JSON entity objects and uses a second-level cache for improving performance.

module name: Recommender  
module description: The Recommender service generates product recommendations for users based on current shopping carts, previous orders, and general item popularity. It features multiple algorithms including Slope One for collaborative filtering and order-based nearest-neighbor approaches.

module name: Registry  
module description: The Registry service maintains information about the online status and location of service instances, requiring periodic heartbeat signals from services to ensure they're active. It facilitates easy configuration of multiple parallel TeaStore instances.
