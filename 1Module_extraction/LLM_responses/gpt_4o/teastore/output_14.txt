module name: WebUI
module description: Manages the front-end of the TeaStore using Servlets and JSP files, retrieving images from the Image Provider and providing a status page of the current state of the TeaStore.

module name: Auth
module description: Handles user authentication, hashing passwords with BCrypt, salting and hashing session cookies to validate sessions.

module name: Persistence
module description: Provides access to the relational database back-end, mapping relational entities to JSON entity objects using EclipseLink JPA ORM mapper, and featuring endpoints for CRUD operations.

module name: Recommender
module description: Generates individual product recommendations for each user based on current shopping cart, previous orders, and user behavior, using various algorithms including item-based collaborative filtering and nearest-neighbor approach.

module name: Registry
module description: Provides information about the online status and location of service instances, allowing service registration and monitoring of heartbeat signals to track online status.

module name: ImageProvider
module description: Retrieves and delivers images to the WebUI as base64 encoded strings, with caching for speedy delivery, and matching product ID or UI name to unique image identifiers.
