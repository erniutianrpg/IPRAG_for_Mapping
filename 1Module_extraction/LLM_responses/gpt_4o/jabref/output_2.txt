module name: Model  
module description: The Model module is the core of the architecture and represents the most important data structures, such as BibDatases, BibEntries, Events, and related aspects. It contains minimal logic and maintains no dependencies on other parts of the application.

module name: Logic  
module description: The Logic module acts as an intermediate layer responsible for reading, writing, importing, exporting, and manipulating the data structures contained within the Model. It is structured as an API for the GUI to interact with the Model.

module name: GUI  
module description: The GUI module is the outer shell of the architecture and interacts with the user. It manages user preferences and facilitates task-solving based on user interaction.

module name: CLI  
module description: The CLI module encompasses all classes that are responsible for the command line interface of the application, enabling interaction through command-line commands.

module name: Preferences  
module description: The Preferences module stores and manages information that can be customized by the user to cater to personal needs and enhance the user experience.

module name: Utility Packages  
module description: Utility packages include ancillary functions and packages that support preferences management and command-line interface (CLI) operations.

module name: Event Bus  
module description: The Event Bus is a communication system that publishes events from the Model to other layers, allowing for dynamic reaction to changes within the core, while preserving the architectural structure.
