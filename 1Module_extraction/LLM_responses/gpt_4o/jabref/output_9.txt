module name: Model  
module description: The Model module represents the core data structures, including BibDatases, BibEntries, Events, and related aspects. It serves as the central component of the architecture, with minimal logic attached, and is independent from the other classes of JabRef.

module name: Logic  
module description: The Logic module acts as an intermediate layer responsible for operations such as reading, writing, importing, exporting, and manipulating the data within the Model. It is structured as an API that the GUI can call and use, and it should only depend on classes within the Model.

module name: GUI  
module description: The GUI module forms the outer shell responsible for interacting with the user, understanding user preferences, and assisting the user in solving tasks. It is the only module that knows the user and handles user interface concerns.

module name: CLI  
module description: The CLI module consists of classes responsible for managing JabRef's command line interface, allowing operations to be executed via command line inputs.

module name: Preferences  
module description: The Preferences module encompasses all information that a user can customize according to personal needs, managing settings that affect user experience.

module name: Utilities  
module description: The Utilities module includes additional packages providing various supportive functions, including handling preferences and command line operations.

module name: Event Bus  
module description: The Event Bus is a mechanism used to publish events from the Model to other layers, facilitating communication across the architecture and allowing the outer layers to react to changes within the core.
