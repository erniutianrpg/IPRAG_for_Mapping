module name: Model  
module description: This module represents the core data structures, including BibDatases, BibEntries, Events, and related aspects. It has minimal logic attached, maintains no dependencies on other JabRef classes, and serves as the central component of the architecture.

module name: Logic  
module description: The Logic module is responsible for operations such as reading, writing, importing, exporting, and manipulating the Model. It acts as an API that the GUI can call and use, with dependencies directed towards the Model.

module name: GUI  
module description: The GUI module serves as the outer shell of the architecture, responsible for user interaction. It knows the user's preferences and assists in task completion but should only depend on the Logic module.

module name: Preferences  
module description: This module captures all customizable information set by the user to cater to personal needs, interacting primarily with the GUI module.

module name: CLI  
module description: The CLI (Command Line Interface) module bundles classes responsible for managing JabRef's interactions through the command line.

module name: Utility Packages  
module description: These packages provide supplementary functionalities and assist the main components, supporting preferences and CLI operations.

module name: Event Bus  
module description: The Event Bus facilitates communication between the Model and other layers by publishing events, allowing architectural integrity while enabling reactivity to core changes.
