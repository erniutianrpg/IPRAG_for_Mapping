module name: Model  
module description: The Model module represents the core data structures, such as BibDatases, BibEntries, Events, and related aspects. It has minimal logic attached and should have no dependencies on other JabRef classes.

module name: Logic  
module description: The Logic module is responsible for reading, writing, importing, exporting, and manipulating the model. It is structured as an API that the GUI can call and use, and should only depend on model classes.

module name: GUI  
module description: The GUI module is the outer shell, interacting with the user and managing user preferences to help solve tasks. It has dependencies directed towards the center and acts based on changes in the model using the event bus.

module name: CLI  
module description: The CLI module bundles classes that manage JabRef¡¯s command line interface operations.

module name: Preferences  
module description: The Preferences module encompasses all information customizable by a user for personal configuration needs. 

module name: Utility Packages  
module description: Various utility packages that support functions related to preferences and CLI, helping maintain structured architecture.
