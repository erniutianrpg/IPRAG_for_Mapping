module name: Model  
module description: Represents the main data structures such as BibDatases, BibEntries, and Events with minimal logic attached. It acts as the core of the architecture and has no dependencies on other JabRef classes.

module name: Logic  
module description: Acts as an intermediate layer responsible for reading, writing, importing, exporting, and manipulating the Model. It is structured as an API that the GUI can call and use, and it depends only on the Model.

module name: GUI  
module description: Serves as the outer shell of the architecture, interacting with the user to help solve tasks and manage user preferences. It is the only layer aware of the user and his preferences.

module name: CLI  
module description: Contains classes responsible for JabRef's command line interface, providing interaction through command prompts.

module name: Preferences  
module description: Represents all information customizable by a user for her personal needs, encapsulating user-specific settings and preferences.

module name: Event Bus  
module description: Facilitates the publishing of events from the Model to other layers, enabling the architecture to remain structured while allowing the outer layers to react to changes within the core.
