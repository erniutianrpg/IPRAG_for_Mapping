module name: Model  
module description: The Model module represents the core data structures in the architecture, including BibDatasets, BibEntries, Events, and related aspects. It contains minimal logic and no dependencies on other classes.

module name: Logic  
module description: The Logic module acts as an intermediary layer between the Model and the GUI, responsible for reading, writing, importing, exporting, and manipulating the Model data. It serves as an API for the GUI to interact with the Model.

module name: GUI  
module description: The GUI module forms the outer shell of the architecture, interacting directly with the user and handling preferences. It utilizes the Logic module to perform tasks that involve the Model.

module name: CLI  
module description: The CLI (Command Line Interface) module bundles classes responsible for handling command line interactions with the application.

module name: Preferences  
module description: The Preferences module represents user-customizable information, allowing personalization of the application to suit individual needs.

module name: Event Bus  
module description: The Event Bus module facilitates communication between the Model and other layers, enabling the system to respond to changes in the Model without compromising the architecture structure.
