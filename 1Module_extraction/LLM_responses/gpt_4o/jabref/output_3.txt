module name: Model  
module description: The Model module represents the core data structures, such as BibDatabases, BibEntries, and Events. It maintains minimal logic and is independent of other classes in the application.

module name: Logic  
module description: The Logic module is responsible for operations on the model, including reading, writing, importing, exporting, and data manipulation. It serves as an API for the GUI to perform these actions.

module name: GUI  
module description: The GUI module handles user interaction, manages user preferences, and is the outer shell of the architecture. It relies on the Logic module to interact with the model and assist users in solving tasks.

module name: CLI  
module description: The CLI (Command Line Interface) module encompasses classes related to JabRef's command line operations, providing users with an alternative interface to interact with the application.

module name: Preferences  
module description: The Preferences module contains all user-customizable settings, allowing personalization according to user needs and preferences.

module name: Event Bus  
module description: The Event Bus facilitates communication by publishing events from the model to the other layers, enabling responsive interaction while maintaining architectural integrity.
