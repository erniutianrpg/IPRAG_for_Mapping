module name: Facade  
module description: A server-side web front end that delivers websites to users and provides session management. It handles user registration and login, forwards users to the audio files listing site, and allows browsing, downloading, and uploading of audio files.

module name: MediaManagement  
module description: Central business logic component that coordinates communication between components, processes download requests by fetching audio files, and forwards re-encoded and watermarked audio files to users.

module name: UserManagement  
module description: Handles user registration and authentication, implements hashing and salting of passwords for security, and coordinates with database adapters for user data storage and retrieval.

module name: TagWatermarking  
module description: Re-encodes requested audio files and adds unique digital watermarks to connect each downloaded file with a user ID to prevent copyright infringements.

module name: Packaging  
module description: Archives multiple audio files into a single compressed file for simultaneous downloads.

module name: ReEncoder  
module description: Converts the bit rates of audio files, potentially reducing file sizes to facilitate downloads.

module name: Database  
module description: Stores user information, salted hashes of passwords, and audio file metadata such as name and genre; executes queries for user and file data.

module name: AudioAccess  
module description: Creates and sends queries to the Database component to list all available audio files.

module name: MediaAccess  
module description: Encapsulates database access for audio file metadata, stores uploaded files, and retrieves requested files and their metadata from the Database and DataStorage.

module name: UserDBAdapter  
module description: Encapsulates database access for user data, creates queries based on user requests, and interfaces with the Database component.

module name: DataStorage  
module description: Dedicated storage location, separate from the database, that stores all audio files and provides retrieval for download requests.
