module name: Facade  
module description: The Facade component is a server-side web front end responsible for delivering websites to users, providing session management, offering user registration and log-in functionalities, and allowing users to browse, download, and upload audio files.

module name: MediaManagement  
module description: The MediaManagement component serves as the central business logic layer, coordinating communication between other components. It fetches audio files for processing download requests and forwards watermarked files to users.

module name: UserManagement  
module description: The UserManagement component handles user registration and authentication requests. It also implements functions to hash and salt user passwords securely.

module name: UserDBAdapter  
module description: The UserDBAdapter component manages database access specifically for user data, creating queries based on user requests and interacting with the database.

module name: TagWatermarking  
module description: The TagWatermarking component digitally and individually watermarks re-encoded audio files to connect each downloaded file uniquely to a user ID.

module name: Packaging  
module description: The Packaging component archives multiple audio files into a single compressed file to enable users to download several files at once.

module name: ReEncoder  
module description: The ReEncoder component converts the bit rates of audio files, potentially reducing file sizes for efficient storage and transfer.

module name: Database  
module description: The Database component represents the actual database system (e.g., MySQL) used for storing user information, salted password hashes, and meta-data of audio files, such as names and genres.

module name: AudioAccess  
module description: The AudioAccess component generates queries to retrieve a list of all available audio files by interacting with the Database component.

module name: MediaAccess  
module description: The MediaAccess component manages database access for audio file meta-data, stores uploaded audio files at predefined locations, and retrieves audio files from DataStorage based on user requests and meta-data.

module name: DataStorage  
module description: The DataStorage component is responsible for storing all audio files at a specific location, separate from the database, ensuring the decoupling of file storage from database operations.
