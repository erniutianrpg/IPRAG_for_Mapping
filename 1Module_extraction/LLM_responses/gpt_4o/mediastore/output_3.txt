module name: Facade  
module description: The Facade component serves as the server-side web front end, responsible for delivering websites to users, managing user sessions, providing user registration and log-in pages, and enabling the browsing, downloading, and uploading of audio files.

module name: MediaManagement  
module description: The MediaManagement component manages the application business logic, coordinates communication between components, processes download requests, and forwards processed audio files to users.

module name: UserManagement  
module description: The UserManagement component handles user registration and authentication, implements password hashing and salting, and collaborates with the UserDBAdapter for user-related database operations.

module name: UserDBAdapter  
module description: The UserDBAdapter component manages database access related to user data, creating queries based on user requests, and interacting with the Database component.

module name: TagWatermarking  
module description: The TagWatermarking component applies digital watermarking to downloaded audio files to uniquely associate them with a user ID, helping prevent copyright infringements.

module name: Packaging  
module description: The Packaging component creates archives of multiple audio files into a single compressed file for downloading several files simultaneously.

module name: ReEncoder  
module description: The ReEncoder component alters the bit rates of audio files, potentially reducing file sizes as part of the download process.

module name: Persistence Tier  
module description: The Persistence Tier includes components responsible for storing audio files and their meta-data.

module name: Database  
module description: The Database component is the actual database that stores user information and meta-data of audio files such as names and genres and executes queries created by other components.

module name: MediaAccess  
module description: The MediaAccess component handles database access for audio file meta-data, manages file uploads, retrieves audio file lists, and ensures the delivery of correct files during the download process.

module name: DataStorage  
module description: The DataStorage component stores the actual audio files separately from the database, providing a predefined location such as a dedicated file server or local disk.
