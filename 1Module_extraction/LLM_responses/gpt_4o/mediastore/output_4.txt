module name: Facade  
module description: The server-side web front end that delivers websites to users, manages sessions, provides registration and log-in pages, and facilitates browsing, downloading, and uploading of audio files.

module name: MediaManagement  
module description: Coordinates communication between components, manages the main application business logic, fetches audio files for download processing, and forwards watermarked files to users.

module name: UserManagement  
module description: Handles user registration and authentication, including password hashing and salting for security purposes.

module name: UserDBAdapter  
module description: Encapsulates database access for user data, creates queries based on user requests, and interacts with the Database component to execute queries.

module name: TagWatermarking  
module description: Re-encodes and digitally watermarks requested audio files to uniquely connect them to a user's ID, preventing copyright infringements.

module name: Packaging  
module description: Archives multiple audio files into a single compressed file to facilitate downloading several files at a time.

module name: ReEncoder  
module description: Converts the bit rates of audio files, potentially reducing their file sizes.

module name: AudioAccess  
module description: Creates queries to list available audio files and interacts with the Database component to fetch results.

module name: MediaAccess  
module description: Encapsulates database access for audio file meta-data, fetches available audio file lists, retrieves files for download, and stores uploaded files in the DataStorage.

module name: Database  
module description: Represents the actual database that stores user information, salted password hashes, and audio file meta-data. Executes queries generated by other components.

module name: DataStorage  
module description: A dedicated storage location for all audio files, decoupled from the database, where files are stored unchanged unless re-encoding is required during downloads.
