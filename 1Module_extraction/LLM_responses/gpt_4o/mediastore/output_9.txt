module name: Facade  
module description: The Facade component serves as the server-side web front end that handles the delivery of websites to users, session management, user registration, log-in, and allows for browsing, downloading, and uploading of audio files.

module name: MediaManagement  
module description: MediaManagement coordinates communication among components, processes download requests by fetching audio files from storage locations, and forwards watermarked files to users.

module name: UserManagement  
module description: UserManagement handles user registration, authentication, and implements password hashing and salting for security.

module name: UserDBAdapter  
module description: UserDBAdapter manages database queries related to user data, including user authentication processes and the secure storage of salted password hashes.

module name: TagWatermarking  
module description: The TagWatermarking component digitally watermarks reencoded audio files to uniquely associate them with user IDs for copyright protection.

module name: Packaging  
module description: Packaging archives multiple audio files into a single compressed file, enabling users to download several files concurrently.

module name: ReEncoder  
module description: ReEncoder component alters the bit rates of audio files, potentially reducing their file sizes.

module name: Database  
module description: The Database component stores user information, salted password hashes, and meta-data of audio files, executing queries for user and meta-data retrieval.

module name: AudioAccess  
module description: AudioAccess constructs queries to retrieve a list of all available audio files from the Database component.

module name: MediaAccess  
module description: MediaAccess handles the storage of uploaded audio files and their meta-data, fetching audio file lists, and retrieving meta-data for download requests.

module name: DataStorage  
module description: DataStorage is responsible for storing audio files separately from the Database, housing files on a dedicated file server or local disk without changes upon upload.
