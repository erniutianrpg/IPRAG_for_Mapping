module name: Facade  
module description: The Facade component serves as the server-side web front end, responsible for delivering websites to users, managing sessions, facilitating registration and log-in, and enabling browsing, downloading, and uploading of audio files.

module name: MediaManagement  
module description: The MediaManagement component provides application business logic, coordinating communication among components, fetching audio files for downloads from the specified location, and forwarding watermarked files to users after processing by other components.

module name: UserManagement  
module description: The UserManagement component handles user registration and authentication requests, implementing hashing and salting of passwords to enhance security during user login processes.

module name: TagWatermarking  
module description: The TagWatermarking component performs digital watermarking on audio files after re-encoding them, ensuring each downloaded file is uniquely connected to a user ID to deter copyright infringement.

module name: Packaging  
module description: The Packaging component archives multiple audio files into a single compressed file to enable the downloading of several files at a time.

module name: ReEncoder  
module description: The ReEncoder component converts the bit rates of audio files, potentially reducing file sizes during the downloading process.

module name: AudioAccess  
module description: The AudioAccess component creates queries for listing available audio files, which are then sent to the Database component for execution.

module name: MediaAccess  
module description: The MediaAccess component encapsulates database access for meta-data of audio files, fetching lists of available audio files and storing uploads at predefined locations.

module name: UserDBAdapter  
module description: The UserDBAdapter component encapsulates database access for user data, creating and executing queries based on user requests related to registration and authentication.

module name: Database  
module description: The Database component stores user information and meta-data of audio files such as names and genres, executing queries from both AudioAccess and UserDBAdapter components, and storing salted hashes of passwords.

module name: DataStorage  
module description: The DataStorage component stores audio files separately from the database, ensuring efficient retrieval and storage of audio files at predefined locations during user upload and download processes.
