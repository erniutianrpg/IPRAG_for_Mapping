module name: Facade
module description: The server-side web front end responsible for delivering websites to users, providing session management, and enabling user registration and login. It also permits users to browse, download, and upload audio files.

module name: MediaManagement
module description: Central business logic component that coordinates the communication between other components, processes download requests, and manages audio file retrieval and forwarding.

module name: UserManagement
module description: Handles user registration and authentication, including hashing and salting passwords to enhance security.

module name: UserDBAdapter
module description: Queries and encapsulates database access specifically for user data, creating necessary queries based on user requests.

module name: TagWatermarking
module description: Reencodes and digitally watermarks downloaded audio files to uniquely connect them to user IDs, reducing copyright infringement risks.

module name: Packaging
module description: Archives multiple audio files into a single compressed file to allow users to download several files at once.

module name: ReEncoder
module description: Converts audio file bit rates, potentially reducing file sizes.

module name: Database
module description: Stores user information and audio file metadata, including names, genres, and password salted hashes. Executes queries for user and file data.

module name: AudioAccess
module description: Creates queries to access available audio files and sends them to the Database component.

module name: MediaAccess
module description: Manages the storage and retrieval of audio file metadata and coordinates communication with the Database and DataStorage components.

module name: DataStorage
module description: Stores audio files separately from the database to ensure decoupled data storage. Files are stored without alteration, except during download, which may trigger re-encoding.
