module name: Facade  
module description: The Facade module serves as the server-side web front end, delivering websites to users with session management capabilities. It provides registration and log-in functionalities and allows users to browse, download, and upload audio files.

module name: MediaManagement  
module description: The MediaManagement module handles the application business logic, coordinating communication between components and managing audio file fetch operations from storage locations during downloads.

module name: UserManagement  
module description: The UserManagement module manages user registration and authentication processes, including hashing and salting passwords.

module name: UserDBAdapter  
module description: The UserDBAdapter module interfaces with the database to perform queries related to user data, handling functions like database encapsulation.

module name: TagWatermarking  
module description: The TagWatermarking module re-encodes and digitally watermarks audio files before they are delivered to users, enabling unique user identification for downloaded files.

module name: Packaging  
module description: The Packaging module allows the archiving of multiple audio files into a single compressed file for download.

module name: ReEncoder  
module description: The ReEncoder module converts bit rates of audio files, potentially reducing their file sizes before delivery.

module name: Database  
module description: The Database module is responsible for storing user information, salted password hashes, and metadata of audio files.

module name: MediaAccess  
module description: The MediaAccess module manages storage and retrieval operations for audio files and their metadata, interacting with both the Database and DataStorage components.

module name: DataStorage  
module description: The DataStorage module is dedicated to storing audio files at a specific location, separate from the database, to ensure data segregation and efficient file handling.

module name: AudioAccess  
module description: The AudioAccess module creates queries to fetch metadata of audio files from the Database module for presentation to users.
