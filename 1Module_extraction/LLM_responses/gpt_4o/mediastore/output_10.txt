module name: Facade component,  
module description: A server-side web front end that delivers web pages to users, manages sessions, and facilitates user interactions such as registration, log-in, browsing, downloading, and uploading audio files.

module name: MediaManagement component,  
module description: Provides the central application business logic, coordinates communications between components, and manages the fetching and forwarding of audio files for download requests.

module name: UserManagement component,  
module description: Handles user registration and authentication, including hashing and salting passwords to ensure secure storage.

module name: TagWatermarking component,  
module description: Digitally and individually watermarks requested audio files to link them to user IDs, helping to prevent copyright infringements.

module name: Packaging component,  
module description: Archives multiple audio files into a single compressed file to allow users to download several files at a time.

module name: ReEncoder component,  
module description: Converts the bit rates of audio files to potentially reduce file sizes during download processes.

module name: AudioAccess component,  
module description: Creates and sends queries to the Database component to retrieve a list of available audio files for users.

module name: MediaAccess component,  
module description: Manages the storage of audio file meta-data in the database and facilitates the retrieval from the DataStorage for downloads.

module name: UserDBAdapter component,  
module description: Provides functions to encapsulate database access for user data, creating queries based on user requests.

module name: Database component,  
module description: Represents a database storing user information and audio file meta-data, such as names and genres, and executes queries received from other components.

module name: DataStorage,  
module description: Dedicated storage for all audio files, decoupled from the database, used to store uploaded files and retrieve them for downloads without change.
