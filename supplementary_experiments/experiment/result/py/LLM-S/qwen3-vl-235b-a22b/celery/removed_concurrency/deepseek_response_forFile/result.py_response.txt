- `AsyncResult`: represents a single task result; supports `get()`, `ready()`, `failed()`, `revoke()`, `then()`, etc. — this is the canonical interface for interacting with async task results.
- `ResultSet`: container for multiple `AsyncResult`s; supports `join()`, `successful()`, etc.
