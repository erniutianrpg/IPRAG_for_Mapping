### What is a Result Backend?
In Celery, result backends are optional components that store the return values of tasks. They are distinct from brokers (which handle task queueing). Backends like Redis, Database, Memcached, or cloud storage (e.g., S3, Azure Blob) implement `KeyValueStoreBackend` or similar interfaces.

This file implements a **custom result backend** using Azure Block Blobs — not a broker, not a worker, not an app-level config.
