### 2. **What is a “result backend” in Celery?**
- Result backends are pluggable storage systems used to store task return values, states, and chord group results.
- They live under `celery.backends.*`, e.g.:
  - `celery.backends.redis.RedisBackend`
  - `celery.backends.database.DatabaseBackend`
  - `celery.backends.mongodb.MongoBackend`
- The base class `KeyValueStoreBackend` is part of the backend infrastructure.
