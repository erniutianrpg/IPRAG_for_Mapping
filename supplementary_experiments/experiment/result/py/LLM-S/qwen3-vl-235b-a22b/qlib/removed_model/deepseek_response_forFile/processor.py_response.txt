### 2. **What is the purpose of these classes?**
These are **data preprocessors / feature transformers**, designed to:
- Clean data (drop NaN, fill values, remove columns),
- Normalize features (z-score, min-max, robust z-score),
- Perform cross-section operations (CSZScore, CSRank),
- Filter time ranges (instrument-aware),
- Be serializable and reusable in training/inference pipelines.

They follow a consistent pattern:
- `fit()` learns parameters (e.g., mean/std for normalization) on training data,
- `__call__()` applies transformation (during train/infer),
- `readonly()`/`is_for_infer()` indicate whether state changes or inference-only behavior.

This is classic **feature engineering / data preprocessing** logic — part of the data preparation pipeline before feeding into models.
