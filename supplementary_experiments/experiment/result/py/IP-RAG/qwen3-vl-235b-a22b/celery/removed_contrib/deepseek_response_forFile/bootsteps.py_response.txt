### 2. **What is a “Bootstep”?**
In Celery, *bootsteps* are modular components that define how a worker (or other runtime entity) starts up, runs, and shuts down. They form a DAG where dependencies between steps are respected (e.g., “transport must start before consumer”).

The `Blueprint` class manages this DAG, and `Step`/`StartStopStep`/`ConsumerStep` are concrete implementations used by the worker to compose its runtime behavior.

This pattern is central to the **worker’s internal architecture**, specifically how it initializes and manages subcomponents (like event loop, consumer, heartbeat, etc.).
