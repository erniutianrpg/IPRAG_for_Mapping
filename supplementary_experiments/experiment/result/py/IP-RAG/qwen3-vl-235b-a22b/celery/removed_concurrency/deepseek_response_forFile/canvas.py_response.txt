### 2. **Key Classes and Functions**
The file defines:
- `Signature`: base class for all task signatures; supports calling, delaying, chaining, stamping, linking, etc.
- `_chain`, `chain`: sequential task composition.
- `_basemap`, `xmap`, `xstarmap`: map-style parallel execution (like `map()` over tasks).
- `chunks`: chunked parallel execution.
- `group`: concurrent execution of multiple tasks.
- `_chord`, `chord`: group + callback (i.e., “when all tasks in group finish, run this”).
- `StampingVisitor`: visitor pattern for propagating headers/stamps across composed tasks.
- Helper functions like `signature()`, `maybe_signature()`, `_maybe_group()`, etc.
