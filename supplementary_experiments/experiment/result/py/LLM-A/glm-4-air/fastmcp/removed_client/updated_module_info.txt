ModuleDescriptions : {
    "This module covers the fastmcp command-line interface. It is installed automatically with FastMCP and is the primary way to run, test, install, and interact with MCP servers from the terminal. Assign files here when their primary responsibility is terminal command behavior, CLI parsing, or command execution, not merely because they trigger server, client, tool, resource, or prompt functionality."
    "This module covers prompt templates. It primarily handles prompt objects and their management, creating reusable parameterized prompt templates for MCP clients and helping LLMs generate structured, purposeful responses. Assign files here only when prompt definition, prompt template handling, or prompt management is the file's main responsibility."
    "This module covers resources and resource templates, which are data sources that an LLM can read. It loads information into the LLM context to provide knowledge not present in the training data, with the goal of retrieving information idempotently and ideally without side effects. A resource can be a static text file or a dynamic data fragment from a database, and each resource is identified by a unique URI. Assign files here when they implement resource/resource-template behavior rather than generic data handling."
    "This module covers the FastMCP server core. It is the container for tools, resources, and prompts, manages communication with MCP clients, and orchestrates the full server lifecycle. Assign files here when they implement server lifecycle, server composition, or server-side orchestration, not merely because they are used by a server."
    "This module covers MCP tools and the logic for tool definition, registration, management, and invocation. Tools are functions that clients can call to perform operations or access external systems, and this module can control duplicate tool registration behavior and dynamically remove tools from a server. Assign files here when tool behavior, tool metadata, tool registration, or tool invocation is the main responsibility."
    "This module provides reusable internal support capabilities for the FastMCP framework, helping other core modules with schema handling, OpenAPI parsing, log management, test support, caching, decorators, and common type definitions. It does not directly correspond to a single MCP component; instead, it acts as a low-level utility collection that provides infrastructure support for servers, clients, tools, resources, and OpenAPI integration, reducing duplicate implementations and keeping internal framework behavior consistent. Assign files here only when they provide shared low-level support and do not primarily implement CLI, client, prompts, resources, server, or tools."
}
