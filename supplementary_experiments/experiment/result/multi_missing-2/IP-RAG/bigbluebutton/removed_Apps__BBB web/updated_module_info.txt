ModuleDescriptions : {
    "FSESL. The FreeSWITCH Event Socket Layer client module provides client-side protocol, transport, event, command, handler, and connection code used to communicate with FreeSWITCH through the ESL interface. Files in this module usually belong to bbb-fsesl-client or packages under org.freeswitch.esl. This module is about the event socket client library and messaging layer, not the FreeSWITCH voice conference server itself and not Redis PubSub transport."
    "FreeSWITCH. The FreeSWITCH integration module implements BigBlueButton voice conferencing behavior and the application logic that controls or reacts to FreeSWITCH for audio conferences, dial-in, phone integration, voice users, and conference commands. Files in this module usually contain BigBlueButton voice or freeswitch integration logic, for example akka-bbb-fsesl voice action code. Do not classify generic org.freeswitch.esl client protocol classes as FreeSWITCH; those belong to FSESL."
    "Presentation Conversion. This module implements document and slide conversion for presentations, including receiving presentation conversion requests, converting documents to PDF or SVG, processing pages and images, tracking conversion status, and reporting conversion progress. Files in this module usually contain presentation, document conversion, page analysis, SVG, PDF, image resize, or office-to-PDF conversion logic. Do not classify generic BBB web API services or Redis PubSub infrastructure as Presentation Conversion unless the file primarily implements the conversion workflow."
    "Redis DB. This module stores persistent meeting and recording events in Redis as a data store. Files in this module primarily implement Redis-backed event storage, retrieval, persistence, or recording data access. Do not classify publish-subscribe message routing or inter-service notification code as Redis DB; that belongs to Redis PubSub."
    "Redis PubSub. This module provides Redis publish-subscribe communication channels between BigBlueButton applications and services. It carries runtime messages such as meeting events, app-to-service notifications, FreeSWITCH/FSESL coordination messages, and presentation conversion progress notifications. Files in this module primarily implement publishing, subscribing, channel routing, or message transport through Redis PubSub. Do not classify Redis data persistence as Redis PubSub; that belongs to Redis DB."
}
