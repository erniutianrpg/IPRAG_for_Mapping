# bigbluebutton / Apps
## 模块职责
本模块覆盖白板绘图基础支撑、公共API与消息体系定义、会议录制导入导出工具、演示文稿预处理检查四大能力域，核心职责为：
1. 为白板手绘/矢量绘图提供贝塞尔曲线处理与基础几何计算支撑；
2. 定义公共API领域模型与标准化消息结构，支撑跨模块/服务通信；
3. 提供独立的会议录制元数据导入导出工具能力；
4. 提供演示文稿上传前的合规性检查能力，提前识别问题文件。

## 核心功能
1. **白板图形处理**：实现离散手绘点到平滑三次贝塞尔曲线的完整拟合（含去噪、角点检测、参数优化）；支持直线、二次/三次贝塞尔、SVG椭圆弧等多类型路径段的构建、编辑与遍历，可转换为标准Java Shape用于渲染；提供基础几何计算、路径点击命中检测，支撑白板图形交互。
2. **公共API与消息通信**：定义适配XML/JSON序列化的API领域模型；覆盖会议控制、保活、状态变更、录制、访客管理等场景的标准化消息结构；提供统一JSON消息构建工具，支撑内部服务存活探测；提供基于Hibernate的通用数据库访问工具，支持录制数据持久化。
3. **录制导入导出**：支持单个/批量会议录制元数据的导入导出，自动完成元数据XML格式化与持久化，提供命令行、交互式两种运行模式。
4. **演示文稿合规检查**：在PPTX上传预处理阶段检测嵌入EMF图片、异常微小平铺背景、全部幻灯片隐藏三类问题文件，输出标准化退出码供下游流程处理。

## 主要代码区域
- `org.bigbluebutton.core.util.jhotdraw`：白板绘图底层工具包，包含贝塞尔曲线拟合、路径定义、几何计算、命中检测等核心工具类；
- `org.bigbluebutton.api`：公共API核心层，包含API领域模型、消息契约、通用消息封装、数据库访问工具；
- `org.bigbluebutton.api2.domain`：API v2接口的业务数据模型，定义会议时长、录制配置等属性存储结构；
- `org.bigbluebutton.common.messages`：跨模块公共通信消息定义，包含模块存活探测消息结构、标准化消息构建工具；
- `org.bigbluebutton`（bbb-recording-imex）：录制导入导出独立工具，包含启动入口、导入导出核心处理器；
- `org.bigbluebutton.prescheck`：演示文稿合规检查工具，包含启动入口与检查逻辑实现。

## 与其他模块的交互
1. 依赖外部基础库：依赖`java.awt.geom`提供基础图形能力，Gson/Jackson完成JSON/XML序列化，Hibernate提供持久化支撑，Apache POI完成PPTX文件解析；
2. 内部模块依赖：白板图形子模块内部`Bezier`依赖`BezierPath`输出拟合结果、命中检测依赖`Geom`几何工具；录制导入导出依赖数据存储模块与XML服务模块完成数据读写与格式转换；
3. 向上输出能力：为上层白板业务模块提供底层图形计算支撑；为全系统所有模块提供统一的API数据结构与消息通信规范；作为独立工具为录制管理模块、演示文稿上传流程提供导入导出、合规检查能力。

## 架构识别线索
本模块是BigBlueButton的基础能力聚合层，兼具底层公共支撑与独立工具属性：
1. 拆分出独立的`jhotdraw`图形工具包，体现了底层能力与上层白板业务的关注点分离；
2. 统一的API领域模型与消息结构定义，符合微服务架构下跨服务通信的标准化设计要求；
3. 录制导入导出、演示文稿检查以独立工具形式存在，适配BigBlueButton离线处理、预处理分流的架构设计；
4. 公共通信消息、API模型分层（v1/v2）维护，体现了系统接口迭代演进的架构兼容性设计。
