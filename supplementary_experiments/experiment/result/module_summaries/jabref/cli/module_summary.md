# jabref / cli
## 模块职责
JabRef的命令行接口模块，是整个应用的启动入口，负责提供无图形界面的命令行文献管理能力；处理应用启动初始化、命令行参数解析，根据参数决定执行命令行任务、启动图形界面或直接退出；同时依赖核心逻辑与模型层能力支撑全流程命令行文献操作。

## 核心功能
1. **应用启动管控**：作为应用主入口，完成日志初始化、多实例冲突处理、全局偏好与环境初始化、网络配置、旧索引清理等启动前置工作，控制应用后续执行流程。
2. **命令行参数处理**：基于Apache Commons CLI定义所有支持的命令行选项，完成参数解析与值提取，支持版本、帮助、导入导出格式列表的格式化输出；支持远程单实例场景下，接收新实例的命令行参数并远程处理。
3. **核心CLI文献管理功能**：
   - 文献数据库多格式导入导出、搜索结果导出；从LaTeX `.aux`文件提取引用生成子BibTeX数据库；
   - 偏好设置的导入、导出、重置；重新生成文献引用键、自动关联本地文件、写入PDF元数据；网络文献获取；
   - 支持基于BST样式生成格式化参考文献列表，提供BST虚拟机所需全部内置函数；
   - 支持基于ANTLR语法的高级结构化搜索，支持布尔组合、正则匹配、PDF全文搜索与语法校验。
4. **基础能力支撑**：提供文献条目批量清理格式化、引文布局规范转换、多语言国际化输出、通用字符串处理、文件更新监控抽象等底层能力。
5. **架构约束与性能测试**：通过自定义注解管控依赖规则，禁止违规引入GUI组件；基于JMH框架提供核心功能性能基准测试。

## 主要代码区域
1. **CLI核心入口与业务实现**：`org.jabref.cli`包，包含启动入口`Launcher`、参数解析`JabRefCLI`、参数调度`ArgumentProcessor`、aux文件处理`AuxCommandLine`、终端输出`SystemOutputPrinter`；根`module-info.java`定义Java模块依赖与开放规则。
2. **能力支撑层代码**：
   - 远程CLI处理：`org.jabref.logic.remote`及其子包（远程服务实现）、`org.jabref.gui.remote`（CLI消息适配）；
   - BST样式处理：`org.jabref.logic.bst`；
   - 文献批量清理：`org.jabref.logic.cleanup`；
   - 多格式导入支撑：`org.jabref.logic.importer`及其子包；
   - 国际化：`org.jabref.logic.l10n`；
   - 引文格式化：`org.jabref.logic.layout`/`org.jabref.logic.layout.format`；
   - 高级搜索：`org.jabref.model.search.rules`；
   - 通用工具与模型：`org.jabref.model.strings`、`org.jabref.model.util`、`org.jabref.model.entry.field`。
3. **性能测试代码**：`org.jabref.benchmarks`包，基于JMH的性能测试实现。
4. **架构约束定义**：自定义架构管控注解，用于约束CLI模块依赖规则。

## 与其他模块的交互
1. 依赖关系：依赖Apache Commons CLI做参数解析、ANTLR 4做搜索语法解析、JMH做性能测试；强依赖JabRef核心层（模型、导入导出、文献处理、偏好服务等）实现所有业务功能，依赖核心PDF检索组件实现全文搜索。
2. 与GUI模块交互：作为应用入口处理参数后，若无需退出则启动GUI模块；支持GUI单实例运行时，接收新启动实例的CLI参数远程处理并返回结果。
3. 依赖管控：通过自定义架构约束注解，限制CLI模块违规引入AWT/Swing等GUI相关组件，保证CLI可独立无GUI运行。
4. 扩展支持：通过抽象类、接口预留扩展点，支持自定义数据源查询转换、自定义CLI输出实现。

## 架构识别线索
1. 严格区分启动入口职责与业务能力，CLI核心调度仅做参数解析与流程转发，具体文献处理能力全部下沉核心层，符合分层架构设计。
2. 通过自定义注解实现架构依赖规则管控，明确CLI模块不能引入GUI依赖，保证了命令行版本的可裁剪性。
3. 核心能力基于接口抽象，预留扩展点，支持自定义功能接入，符合开放封闭设计原则。
4. 远程参数处理适配单实例运行场景，体现了产品对多启动方式的兼容性设计。
