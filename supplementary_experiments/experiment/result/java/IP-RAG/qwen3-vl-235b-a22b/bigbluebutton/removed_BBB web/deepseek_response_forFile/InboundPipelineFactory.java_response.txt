> "The FreeSWITCH Event Socket Layer client module provides client-side protocol, transport, event, command, handler, and connection code used to communicate with FreeSWITCH through the ESL interface. Files in this module usually belong to bbb-fsesl-client or packages under org.freeswitch.esl."

This is consistent with the role of an ESL client library, which handles the connection and message pipeline setup for communicating with FreeSWITCH via the Event Socket Layer (ESL).

> `SimpleHangupPipelineFactory.java` in `org.freeswitch.esl.client.outbound.example` → assigned to **FSESL**
