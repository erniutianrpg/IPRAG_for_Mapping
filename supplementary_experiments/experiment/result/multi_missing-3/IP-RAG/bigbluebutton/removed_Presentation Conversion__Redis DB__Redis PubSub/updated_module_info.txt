ModuleDescriptions : {
    "Apps. The BigBlueButton Apps service is the meeting orchestration application. It coordinates real-time meeting state, collaboration features, user actions, presentation state, whiteboard and cursor events, external video sharing, and messages sent to or received from other backend services. Files in this module usually belong to akka-bbb-apps or contain core meeting/application logic. Do not classify low-level FreeSWITCH event socket client code, Redis storage code, or generic web request/API code as Apps unless the file primarily implements meeting application behavior."
    "BBB web. The BigBlueButton web application handles web-facing backend responsibilities such as API request models and constraints, meeting entry and callback services, TURN/STUN and web service helpers, load distribution across backend instances, and web-side coordination with other services. Files in this module usually belong to bbb-web or bbb-common-web web/API/service packages. Do not classify presentation conversion implementation, FreeSWITCH voice control, FSESL event socket client code, or Redis infrastructure code as BBB web unless the file primarily implements web/API behavior."
    "FSESL. The FreeSWITCH Event Socket Layer client module provides client-side protocol, transport, event, command, handler, and connection code used to communicate with FreeSWITCH through the ESL interface. Files in this module usually belong to bbb-fsesl-client or packages under org.freeswitch.esl. This module is about the event socket client library and messaging layer, not the FreeSWITCH voice conference server itself and not Redis PubSub transport."
    "FreeSWITCH. The FreeSWITCH integration module implements BigBlueButton voice conferencing behavior and the application logic that controls or reacts to FreeSWITCH for audio conferences, dial-in, phone integration, voice users, and conference commands. Files in this module usually contain BigBlueButton voice or freeswitch integration logic, for example akka-bbb-fsesl voice action code. Do not classify generic org.freeswitch.esl client protocol classes as FreeSWITCH; those belong to FSESL."
}
