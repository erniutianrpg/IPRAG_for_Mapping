### What is HHT?
Hilbert–Huang Transform is a **time-frequency analysis method** that decomposes a signal into Intrinsic Mode Functions (IMFs) via EMD, then applies Hilbert transform to obtain instantaneous frequency and amplitude. It is **nonlinear, adaptive, and data-driven**, unlike STFT or wavelet transforms.

It is *not* a spectral filter bank, not a feature extractor per se (though features can be derived from it), not primarily for MIR tasks like pitch/onset (though could support them indirectly), and not part of standard audio I/O/resampling.
