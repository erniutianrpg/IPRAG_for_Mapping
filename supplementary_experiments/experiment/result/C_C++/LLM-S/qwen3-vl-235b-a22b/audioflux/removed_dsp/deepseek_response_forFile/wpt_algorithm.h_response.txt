### What is WPT?
Wavelet Packet Transform (WPT) is a time-frequency analysis method that generalizes the Discrete Wavelet Transform (DWT). It decomposes both approximation and detail coefficients at each level, yielding a full binary tree of subbands — useful for adaptive time-frequency representations, feature extraction (e.g., in audio classification), or preprocessing for MIR tasks.
