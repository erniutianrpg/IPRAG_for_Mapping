### What is EMD?
Empirical Mode Decomposition is a **nonlinear, adaptive signal decomposition technique**, used to break a signal into Intrinsic Mode Functions (IMFs). It is:
- Time-frequency localized,
- Data-driven (no fixed basis like Fourier),
- Often used in **non-stationary signal analysis**, including audio, biomedical signals, etc.
- Frequently employed as a preprocessing step before feature extraction or spectral analysis.

It is **not** a standard DSP transform like STFT, DFT, or filter bank — but it *relies on* low-level DSP operations (e.g., interpolation, Hilbert transform, zero-crossing detection). However, EMD itself is more of a *decomposition algorithm* than a basic transform.
