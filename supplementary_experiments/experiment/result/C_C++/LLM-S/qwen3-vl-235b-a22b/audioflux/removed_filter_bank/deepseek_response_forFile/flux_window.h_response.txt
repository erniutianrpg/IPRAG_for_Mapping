### 2. **What are window functions used for?**

- **Spectral analysis** (e.g., STFT, spectrograms): applied before FFT to reduce spectral leakage.
- **Filter design** (e.g., FIR filters via window method).
- **Time-frequency transforms**: essential preprocessing for any transform that uses overlapping windows (e.g., Short-Time Fourier Transform).

They are **low-level building blocks**, not high-level feature extractors or MIR-specific algorithms.
