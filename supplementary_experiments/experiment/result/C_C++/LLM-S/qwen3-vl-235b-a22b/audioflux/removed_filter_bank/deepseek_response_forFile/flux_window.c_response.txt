### 2. **What is a “window function” in signal processing?**
Window functions (Hann, Hamming, Blackman, Kaiser, etc.) are fundamental in:
- STFT / spectrogram computation (to reduce spectral leakage),
- Filter design,
- Overlap-add synthesis,
- Any time-frequency analysis where tapering is needed.

They are **low-level building blocks**, not high-level features or MIR tasks.
