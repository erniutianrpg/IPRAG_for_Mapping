### 2. **What is cross-correlation?**
Cross-correlation is a core **digital signal processing (DSP)** operation used to measure similarity between two signals as a function of displacement (lag). It underlies:
- Time delay estimation,
- Pattern matching,
- Template matching,
- Pitch detection (via autocorrelation),
- Onset detection (in some methods),
- Filter design,
- System identification.

It is *not* itself a high-level feature extractor (like MFCC or spectral centroid), nor is it directly a music information retrieval (MIR) algorithm — though MIR algorithms may *use* it (e.g., autocorrelation-based pitch estimation).
