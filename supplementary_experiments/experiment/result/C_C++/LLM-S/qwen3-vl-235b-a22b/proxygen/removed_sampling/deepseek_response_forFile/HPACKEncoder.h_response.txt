### 2. **What is HPACK?**
HPACK is the header compression format defined in **RFC 7541**, used in **HTTP/2** (and later HTTP/3) to compress HTTP headers efficiently. It involves:
- Static/dynamic header tables
- Indexing, literal encoding, Huffman encoding
- Context management (`HPACKContext`)
- Encoder/decoder state machines

Thus, this file is part of the **HTTP/2 codec layer**, specifically the *header compression encoder*.
