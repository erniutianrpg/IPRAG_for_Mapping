### 2. **What is HPACK?**
HPACK is the header compression format defined in **HTTP/2** (RFC 7541). It is used to compress HTTP header fields before transmission over HTTP/2 connections. The encoder side (`HPACKEncoder`) is responsible for:
- Encoding header sets into HPACK binary format.
- Managing static/dynamic header tables.
- Choosing between indexed, literal with indexing, or literal without indexing representations.
- Interfacing with output buffers (`folly::IOBufQueue`).

Thus, this class is a core part of **HTTP/2 codec implementation**, specifically the *encoding* side of header compression.
