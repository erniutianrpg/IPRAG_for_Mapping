### 2. **What is QPACK?**
- QPACK is the header compression scheme for HTTP/3.
- It replaces HPACK (used in HTTP/2) but extends it with additional features like dynamic table synchronization via encoder/decoder streams.
- The implementation involves:
  - Decoding header blocks from data streams (`decodeStreaming`, `decodeHeaderQ`)
  - Handling encoder stream instructions (`decodeEncoderStream`, `decodeEncoderStreamInstruction`)
  - Managing dynamic table state, insert counts, base indices, etc.
  - Interfacing with HPACK-style decode buffers (`HPACKDecodeBuffer`)
