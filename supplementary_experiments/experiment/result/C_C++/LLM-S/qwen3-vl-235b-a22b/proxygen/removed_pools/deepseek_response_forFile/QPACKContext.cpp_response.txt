### 2. **What is QPACK?**
- QPACK is the header compression format used in **HTTP/3**, defined in [RFC 9204](https://datatracker.ietf.org/doc/html/rfc9204).
- It replaces HPACK (used in HTTP/2) and introduces bidirectional decoding with dynamic table and static table, plus *blocking* and *stream dependencies* (though this file doesn’t implement blocking, just context/table access).
- The `QPACKContext` class manages the encoder/decoder state: dynamic table, static table reference, tracking of references, etc.
