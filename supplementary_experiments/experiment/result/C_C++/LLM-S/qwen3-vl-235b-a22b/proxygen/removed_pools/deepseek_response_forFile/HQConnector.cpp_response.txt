### 4. **Architectural nuance**
In Facebook’s Proxygen (and Meta’s open-source version):
- `proxygen/lib/http/` contains:
  - `HTTPConnector`, `HQConnector`
  - `HTTPSession`, `HQSession`
  - codec, headers, early data, etc.
- These are considered part of the **HTTP protocol implementation**, even when using QUIC — because they map HTTP semantics (requests/responses, transactions, sessions) onto the transport.
- The *pure* QUIC transport (e.g., `QuicSocket`, `FollyQuicAsyncUDPSocket`, `CongestionControllerFactory`) lives in `quic/` (external or internal), and `proxygen` consumes it.
- So `HQConnector` is a bridge between HTTP and QUIC — but architecturally placed in `http_general`.
