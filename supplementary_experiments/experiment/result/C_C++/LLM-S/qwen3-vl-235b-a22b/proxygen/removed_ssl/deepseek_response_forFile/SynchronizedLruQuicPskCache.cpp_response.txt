### 2. **What is a PSK in QUIC?**
In QUIC (especially with TLS 1.3), a PSK (Pre-Shared Key) is used for 0-RTT resumption. The server caches PSKs (often derived from session tickets) to allow fast resumption. This cache must be:
- Thread-safe (since multiple connections may access it concurrently),
- Size-bounded (LRU eviction),
- Time-aware (PSKs expire).

This is clearly a **transport-layer concern**, specifically tied to **QUIC session resumption**, not HTTP semantics.
