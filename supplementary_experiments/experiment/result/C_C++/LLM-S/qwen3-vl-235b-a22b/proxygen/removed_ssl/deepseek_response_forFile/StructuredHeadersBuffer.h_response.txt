### 2. **What are Structured Headers?**
- Defined in [RFC 8941](https://datatracker.ietf.org/doc/html/rfc8941) and [RFC 8941bis](https://datatracker.ietf.org/doc/html/draft-ietf-httpbis-header-structure-19).
- A standardized way to encode complex header values (booleans, integers, floats, strings, tokens, binary, lists, dictionaries) in HTTP headers.
- Used in modern HTTP features like WebTransport, Priority, Cache Digests, etc.
- Implementation lives under `proxygen/lib/http/structuredheaders/` — clearly part of **HTTP protocol layer**, not transport, DNS, or services.
