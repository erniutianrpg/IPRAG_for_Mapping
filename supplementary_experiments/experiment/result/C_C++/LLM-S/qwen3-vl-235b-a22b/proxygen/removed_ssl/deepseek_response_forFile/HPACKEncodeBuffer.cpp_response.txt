### **2. What is HPACK?**
HPACK is the header compression format defined in **RFC 7541**, used in **HTTP/2** (and also in HTTP/3). It compresses HTTP headers using static/dynamic tables and Huffman coding. This is a core part of the HTTP/2 protocol stack.

Thus, this file implements low-level **HTTP header encoding**, specifically for HTTP/2 (and by extension, HTTP/3).
