### 2. **What is QPACK?**
- QPACK is the header compression format used in **HTTP/3** (RFC 9204), replacing HPACK from HTTP/2.
- It involves:
  - A **dynamic header table**
  - A **static header table**
  - **Context** managing state (insertions, references, blocking, etc.)
- This class (`QPACKContext`) is part of the *codec layer* — specifically, the **compression/decompression logic** for HTTP headers in HTTP/3.
