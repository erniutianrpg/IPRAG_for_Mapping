### 2. **What is QPACK?**
- QPACK is the header compression format for **HTTP/3**, defined in [RFC 9204](https://datatracker.ietf.org/doc/html/rfc9204).
- It replaces HPACK (used in HTTP/2) and introduces bidirectional indexing and dynamic table management with dependencies and blocking.
- `QPACKContext` holds the state needed to decode/encode headers: dynamic table, static table, tracking of references, blocked inserts, etc.
- This is **protocol-level encoding/decoding logic**, not transport, not service, not SSL.
