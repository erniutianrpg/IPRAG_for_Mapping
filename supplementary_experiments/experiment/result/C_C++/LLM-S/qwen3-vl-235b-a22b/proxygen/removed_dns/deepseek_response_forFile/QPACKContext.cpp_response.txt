### 2. **What is QPACK?**
- QPACK is the header compression format defined in [RFC 9204](https://datatracker.ietf.org/doc/html/rfc9204) for HTTP/3.
- It is used in HTTP/3 (QUIC-based) to compress request/response headers, replacing HPACK used in HTTP/2.
- The `QPACKContext` class handles decoding/encoding context: tracking static/dynamic tables, base indexing, reference counting — core *codec* logic.
