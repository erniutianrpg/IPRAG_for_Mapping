- Channel negotiation & management (open/close channel)

This is clearly an **IPC interface definition** for the *sink side* — i.e., what the controller can call on the controlled device.

### Key Insight:
In OHOS architecture, `IRemoteBroker`-derived interfaces like `IDistributedCameraSink` are typically defined in the *manager* module that owns the remote service. Reference pattern: In OHOS distributed systems, the `_Mgr` modules define and implement the `Ixxx` remote interfaces (e.g., `IDistributedCameraSource` would be in `DistributedCameraSourceMgr`). Here, `IDistributedCameraSink` logically resides in `DistributedCameraSinkMgr`.
