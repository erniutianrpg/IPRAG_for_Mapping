### 2. **What is an “Event Command”?**
In distributed systems, especially IPC-based ones:
- Commands are used to send control instructions (e.g., start preview, stop recording).
- Events are used to notify state changes or results (e.g., device connected, error occurred, frame ready).
- This file handles **event commands**, i.e., structured messages that carry event data over IPC or channels.

The presence of:
- `EventType`, `EventResult`, `EventContent`
- Use of JSON for transport
- Belonging to `DistributedHardware` namespace

→ strongly indicates this is part of the **protocol layer** for event exchange between source and sink.
