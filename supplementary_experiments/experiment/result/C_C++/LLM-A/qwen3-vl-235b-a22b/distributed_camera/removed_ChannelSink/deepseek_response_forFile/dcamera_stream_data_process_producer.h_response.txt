This class is a **producer** that:
- Receives raw or processed stream data (via `FeedStream`)
- Buffers it (using queue + mutex/condvar)
- Runs in its own thread (`producerThread_`)
- Periodically pushes data to a driver (`FeedStreamToDriver`)
- Controls timing via `interval_` (FPS-based)
