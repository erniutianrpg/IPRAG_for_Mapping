Key insight:  
In distributed camera architecture:
- The **source side** (controller) initiates operations (e.g., register/unregister camera).
- The **sink side** (controlled device) performs the operation and reports result back to the source via a callback interface like this one.
- Since this interface is implemented on the **source side** and invoked by the **sink side**, it belongs to the **source-side IPC contract** for receiving notifications.
