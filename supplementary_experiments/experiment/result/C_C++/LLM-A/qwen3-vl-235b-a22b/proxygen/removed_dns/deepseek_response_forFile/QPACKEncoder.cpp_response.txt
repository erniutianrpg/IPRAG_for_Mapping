### 2. **What is QPACK?**
- QPACK is the header compression format used in **HTTP/3**, replacing HPACK (used in HTTP/2).
- It involves:
  - Encoding headers on the encoder side (`encode`, `startEncode`, `completeEncode`, etc.)
  - Handling dynamic table updates
  - Managing decoder streams, acknowledgments, insert count increments, etc.
- This is strictly part of the **HTTP protocol layer**, specifically the **codec/compression sublayer** for HTTP/3.
