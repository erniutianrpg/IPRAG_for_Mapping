### 2. **What is a QUIC token?**
In QUIC (especially HTTP/3), the server may issue a *token* during connection establishment (e.g., for address validation or 0-RTT resumption). The client caches this token for future connections to the same server. `QuicTokenCache` is the abstraction for storing/retrieving these tokens.

This class provides **persistent** storage of QUIC tokens on disk (via `FilePersistentCache`), so tokens survive process restarts.
