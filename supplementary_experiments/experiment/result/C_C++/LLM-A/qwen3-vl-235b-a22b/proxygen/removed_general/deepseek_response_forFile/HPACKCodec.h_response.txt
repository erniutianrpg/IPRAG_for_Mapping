### 2. **What is HPACK?**
HPACK is the header compression format used in **HTTP/2** (and also relevant for HTTP/3). It is part of the HTTP protocol specification — specifically, the *header compression layer* that sits below the HTTP semantics but above the transport.

In Proxygen, the `HPACKCodec` class implements the core logic for compressing and decompressing HTTP headers per the HPACK spec. This is tightly coupled with HTTP message encoding/decoding and is part of the HTTP codec stack.
