### 2. **What is HPACK?**
HPACK is the header compression scheme used in HTTP/2 (and also relevant for HTTP/3). It maintains dynamic header tables on both client and server sides, tracking how headers are encoded/decoded, inserted, evicted, etc. The metrics here reflect internal state of those tables.

So this file defines **data structures to capture and compare HPACK compression statistics** — likely used for monitoring, debugging, or logging compression efficiency.
