### What is Consistent Hashing?
Consistent hashing is a technique used in distributed systems to assign keys to nodes (e.g., backend servers) in a way that minimizes reassignment when nodes are added/removed. It's commonly used in:
- Load balancers
- Proxy backends
- Service discovery / routing layers
- Pool selection logic

In Proxygen, this would be used to select a backend server from a pool based on a request key (e.g., host, path, or session ID).
