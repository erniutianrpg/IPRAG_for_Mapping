HPACK is the header compression format used in HTTP/2 (and also relevant for HTTP/3). It defines how HTTP headers are encoded/decoded for transmission over the wire.

- Integer decoding (prefix-length encoding)
- Literal header field decoding
- Buffer boundary checks (e.g., `EOB_LOG` for end-of-buffer errors)

This is **low-level protocol decoding logic**, specifically for HTTP/2 header compression.
