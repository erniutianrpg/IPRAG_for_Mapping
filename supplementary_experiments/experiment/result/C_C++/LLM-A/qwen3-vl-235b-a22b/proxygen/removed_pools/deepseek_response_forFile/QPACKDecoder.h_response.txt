### 2. **What is QPACK?**
- QPACK is the header compression format defined in [RFC 9204](https://datatracker.ietf.org/doc/html/rfc9204) for HTTP/3.
- It replaces HPACK (used in HTTP/2) and introduces bidirectional compression with dynamic table synchronization via an encoder stream.
- This file implements the *decoder* side of QPACK — i.e., how a receiver (e.g., HTTP/3 server or client) decodes compressed header blocks and processes encoder stream instructions.
