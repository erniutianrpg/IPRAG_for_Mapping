### 2. **What is this code doing?**
This file implements **stream dispatching logic for HTTP/3 (HQ)** on top of QUIC. It:
- Listens to incoming data on QUIC streams via `QuicSocket::PeekCallback`.
- Parses stream prefacing (to identify stream type: control, request, push, WebTransport, etc.).
- Manages temporary ownership of streams while waiting for full header/preface parsing.
- Uses timeouts to reject streams that stall during dispatch.
- Delegates actual handling to concrete dispatchers (`HQUniStreamDispatcher`, `HQBidiStreamDispatcher`) — though those are not defined here, they’re implied.
