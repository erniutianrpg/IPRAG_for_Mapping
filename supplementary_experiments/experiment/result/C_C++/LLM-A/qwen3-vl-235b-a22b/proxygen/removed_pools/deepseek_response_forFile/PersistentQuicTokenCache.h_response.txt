### 2. **What is a QUIC token cache?**
In QUIC, the server issues a token during connection establishment (often during the first connection), which the client can present later to enable 0-RTT resumption. The client must cache this token persistently (e.g., on disk) so it survives process restarts.

Thus, this class is tightly coupled with **QUIC transport-layer functionality**, specifically the *client-side token caching* needed for HTTP/3 (which runs over QUIC).
