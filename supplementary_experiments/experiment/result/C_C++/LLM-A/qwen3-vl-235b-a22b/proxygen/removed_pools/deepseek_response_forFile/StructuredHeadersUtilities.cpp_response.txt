### 2. **What are Structured Headers?**
Structured Headers are a standardized format for encoding structured data in HTTP header fields (defined in [RFC 8941](https://datatracker.ietf.org/doc/html/rfc8941)). They define syntax and semantics for identifiers, strings, integers, booleans, binary content, etc., used in modern HTTP headers (e.g., in Web Push, Cache Digests, etc.).
