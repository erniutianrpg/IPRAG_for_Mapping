### 2. **What is a PSK in QUIC context?**
In QUIC (especially with TLS 1.3), PSKs are used for 0-RTT resumption. A cached PSK includes:
- Ticket (session ticket)
- Server cert identity
- Expiration time
This cache is used during connection setup to resume sessions without full handshake.

So this is **transport-layer state management**, specifically for **QUIC session resumption**, and tightly coupled with QUIC transport semantics.
