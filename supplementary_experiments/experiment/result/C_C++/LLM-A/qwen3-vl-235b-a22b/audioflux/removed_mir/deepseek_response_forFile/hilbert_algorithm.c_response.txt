### 2. **What is the Hilbert Transform?**
- A fundamental DSP operation used to compute the analytic signal.
- Enables extraction of instantaneous amplitude/phase, envelope detection, quadrature demodulation, etc.
- Not a feature extractor per se, but a *low-level signal processing primitive*.
- Widely used as a building block for higher-level operations (e.g., envelope, instantaneous frequency), but itself is a core transform.
