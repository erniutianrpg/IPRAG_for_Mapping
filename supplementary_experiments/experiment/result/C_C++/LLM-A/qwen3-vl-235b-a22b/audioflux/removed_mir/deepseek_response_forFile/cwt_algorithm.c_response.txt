### 2. **What is CWT?**
Continuous Wavelet Transform (CWT) is a time-frequency analysis method that uses wavelets (e.g., Morse, Morlet) scaled across frequencies to produce a time-scale representation. It is closely related to filter banks: in practice, CWT can be implemented via convolution with scaled wavelets or via frequency-domain filtering using a filter bank (especially for real-time or efficient implementations).

The struct `OpaqueCWT` holds:
- `FFTObj`, `DFTObj`: used for frequency-domain computation.
- `mFilterBankArr`, `mFilterBankDetArr`: precomputed filter bank coefficients (likely wavelet filters at different scales).
- `realArr1`, `imageArr1`, etc.: complex buffers for intermediate results.
- Parameters like `samplate`, `lowFre`, `highFre`, `binPerOctave`, `waveletType`, `scaleType`, `gamma`, `beta`: all define the CWT configuration.

This strongly suggests the file implements a **CWT engine**, likely using a filter-bank-based approach (as indicated by inclusion of `cwt_filterBank.h` and use of `mFilterBankArr`).
