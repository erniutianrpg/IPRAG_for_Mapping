### 2. **What is NSGT?**
NSGT is a *time-frequency transform* that generalizes the Short-Time Fourier Transform (STFT) using non-uniform (e.g., logarithmic or perceptually motivated) frequency sampling. It's often used in audio analysis for better resolution at low frequencies (e.g., mimicking auditory perception), and is closely tied to *filter bank design* — especially *non-uniform filter banks* like those used in auditory modeling.

Key points:
- NSGT is implemented via a filter bank (analysis/synthesis).
- The file uses `auditory_filterBank.h` and `nsgt_filterBank.h`, indicating it builds/uses a specific filter bank structure.
- It manages windows, FFT/DFT, and time-frequency tiling — but **not** as a generic STFT (which would be in `dsp`), but as a *structured, configurable filter bank-based transform*.
