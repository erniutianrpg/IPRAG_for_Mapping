### 2. **What are window functions?**
Window functions (e.g., Hann, Hamming, Kaiser) are fundamental building blocks in digital signal processing (DSP), especially for:
- Short-Time Fourier Transform (STFT)
- Spectral analysis
- Filter design
- Reducing spectral leakage

They are *not* features themselves, nor part of filter banks (though used *by* them), nor directly MIR-specific (though MIR uses them as a prerequisite).
