### 2. **What is Synchrosqueezing?**
- It is a post-processing method applied *after* STFT or wavelet transforms.
- It improves time-frequency resolution by "squeezing" the transform along the frequency axis using phase information (instantaneous frequency).
- Core operations include:
  - Phase extraction (`atan2` of real/imag),
  - Phase unwrapping,
  - Derivative estimation (e.g., finite differences → instantaneous frequency),
  - Reassignment/squeezing.

This is **not** a feature extractor per se (like MFCC or spectral centroid), nor is it a filter bank construction module — though it *uses* a spectral representation (likely from STFT). It is also not MIR-specific (e.g., no pitch/onset logic), but rather a **low-level time-frequency refinement algorithm**.
