### 2. **What is Cross-Correlation?**
Cross-correlation is a fundamental DSP operation used to measure similarity between two signals as a function of time lag. It's widely used in:
- Signal alignment / time delay estimation
- Pattern matching
- Pitch detection (via autocorrelation)
- Onset detection (in MIR)
- Template matching in feature extraction

However, the *implementation here* is low-level and generic — it does not assume audio-specific semantics; it works on raw float arrays and provides both direct and FFT-accelerated methods.
