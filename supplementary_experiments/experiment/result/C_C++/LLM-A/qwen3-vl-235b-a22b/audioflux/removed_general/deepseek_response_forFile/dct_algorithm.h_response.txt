### 2. **What is DCT?**
Discrete Cosine Transform is a foundational transform in digital signal processing, widely used in:
- Audio coding (e.g., MP3, AAC use MDCT, which is derived from DCT),
- Image compression (JPEG uses DCT-II),
- Feature extraction (e.g., MFCCs use DCT-II on log filterbank energies).

But crucially, **DCT itself is a mathematical transform**, not a feature extractor or MIR-specific algorithm per se — it's a building block.
