### 2. **What is DCT?**
- DCT is a **time-frequency transform**, closely related to the Fourier transform.
- Widely used in:
  - Audio compression (e.g., MP3, AAC use MDCT, which is derived from DCT)
  - Spectral analysis
  - Feature extraction (e.g., MFCCs use DCT on log mel-spectrogram)
- It is a **foundational transform**, not itself a high-level feature extractor or MIR tool, but rather a building block.
