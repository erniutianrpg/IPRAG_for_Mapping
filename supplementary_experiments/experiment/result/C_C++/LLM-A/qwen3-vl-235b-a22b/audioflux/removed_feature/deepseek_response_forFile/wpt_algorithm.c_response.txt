### 2. **What is WPT?**
Wavelet Packet Transform (WPT) is a time-frequency analysis method that generalizes the Discrete Wavelet Transform (DWT) by decomposing both approximation and detail coefficients at each level — resulting in a full binary tree of subbands. It is used for adaptive time-frequency representation, often in signal denoising, feature extraction, and MIR tasks.

While WPT *can* be used in MIR (e.g., for feature extraction), its implementation here is **low-level**, focusing on:
- Filter coefficient generation
- Convolution-based filtering
- Tree-index management
- Memory layout for packet nodes
- Core algorithmic steps (no high-level semantics like pitch/onset)
