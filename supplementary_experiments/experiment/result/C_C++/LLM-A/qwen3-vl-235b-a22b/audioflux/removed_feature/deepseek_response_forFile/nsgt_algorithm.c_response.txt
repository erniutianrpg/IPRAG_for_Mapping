### 2. **What is NSGT?**
NSGT = Nonstationary Gabor Transform — a time-frequency representation generalizing the Short-Time Fourier Transform (STFT) using non-uniform, adaptive filter banks (often with logarithmic or perceptual frequency spacing). It's closely related to:
- Filter banks (especially auditory or perceptually motivated ones),
- Time-frequency analysis,
- Invertible transforms for signal reconstruction.

It is *not* a basic DSP primitive like FFT or windowing — those are used *inside* NSGT.
It is *not* directly a music information retrieval (MIR) algorithm (e.g., pitch, onset), though NSGT may be used *as a front-end* for MIR tasks.
It is *more specific* than generic “general” audio processing — it implements a particular advanced time-frequency transform.
