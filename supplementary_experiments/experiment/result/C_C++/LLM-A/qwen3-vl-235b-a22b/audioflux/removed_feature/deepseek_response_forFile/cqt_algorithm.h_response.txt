### 2. **What is the Constant-Q Transform (CQT)?**
- A time-frequency transform where frequency bins are logarithmically spaced (octave-based), mimicking human auditory perception.
- Widely used in **Music Information Retrieval (MIR)** for tasks like:
  - Chroma features (pitch class representation)
  - CQCC (used in music genre, instrument classification)
  - Pitch/harmonic analysis
- It is *not* a standard STFT or FFT-based spectrogram; it's a specialized transform with perceptual motivation.

While CQT is a *transform*, it is **not generic DSP** like STFT, resampling, or basic filtering — it's specifically designed for music/audio semantics.
