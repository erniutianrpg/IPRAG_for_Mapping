### 2. **What is Cross-Correlation?**
Cross-correlation (`xcorr`) is a fundamental signal processing operation used to measure similarity between two signals as a function of time lag. It is:
- A **low-level DSP primitive**, often used in:
  - Time delay estimation
  - Pattern matching
  - Pitch detection (e.g., autocorrelation for pitch)
  - Onset detection (in MIR)
  - System identification
- Can be implemented directly (O(n²)) or via FFT (O(n log n)), as shown here.
