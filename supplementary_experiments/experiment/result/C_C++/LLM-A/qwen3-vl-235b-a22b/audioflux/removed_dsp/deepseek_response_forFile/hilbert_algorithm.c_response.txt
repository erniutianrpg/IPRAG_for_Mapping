### 2. **What does Hilbert transform do?**
- Used to compute the **analytic signal**, from which instantaneous amplitude and phase can be derived.
- Commonly used in:
  - Envelope detection (e.g., for AM demodulation),
  - Instantaneous frequency estimation,
  - Creating complex-valued time-frequency representations (e.g., in synchrosqueezing or reassignment),
  - As a building block for other transforms (e.g., analytic wavelet, Gabor, etc.).

It is **not** itself a feature extractor (like MFCC), nor a filter bank, nor directly MIR-specific (though MIR may *use* it), but rather a **core signal processing primitive**.
