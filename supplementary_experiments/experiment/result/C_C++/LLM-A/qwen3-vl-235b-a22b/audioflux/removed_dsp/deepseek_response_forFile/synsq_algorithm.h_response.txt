### 2. **What is Synchrosqueezing?**
Synchrosqueezing is a time-frequency reassignment technique that sharpens time-frequency representations (like STFT or CQT) by relocating energy in frequency based on instantaneous frequency estimates. It is a **time-frequency transform** / **spectral refinement** method — not a feature extractor per se, nor strictly an MIR task (though used *in* MIR), but rather a core signal processing algorithm.
