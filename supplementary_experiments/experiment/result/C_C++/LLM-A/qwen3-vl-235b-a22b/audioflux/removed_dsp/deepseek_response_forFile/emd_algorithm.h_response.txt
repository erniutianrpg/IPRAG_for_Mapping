### What is EMD?
Empirical Mode Decomposition is a data-driven method to decompose a signal into intrinsic mode functions (IMFs), often used for non-stationary and nonlinear signal analysis. When combined with the Hilbert transform, it yields the **Hilbert-Huang Transform (HHT)**, which provides a time-frequency representation.

In audio processing, EMD/HHT has been used for:
- Time-frequency analysis (alternative to STFT, wavelets),
- Feature extraction (e.g., IMF-based features),
- Denoising, pitch estimation (indirectly), etc.

But crucially, EMD is **not** a standard spectral filter bank, nor is it directly a music information retrieval (MIR) primitive like onset detection or HPSS. It is more of a **signal decomposition / time-frequency transform** technique.
