### 2. **What is NSGT?**
NSGT (Non-Stationary Gabor Transform) is a flexible time-frequency analysis tool, generalizing the Short-Time Fourier Transform (STFT) and Gabor frames. It allows non-uniform frequency resolution (e.g., logarithmic/bark scales) via customizable filter banks. It is used for high-resolution spectral analysis, especially in audio processing where perceptual scales matter.

Crucially, NSGT is:
- A **time-frequency transform** (like STFT, wavelet, constant-Q transform),
- Implemented via a **filter bank** (analysis/synthesis filters),
- Not directly a feature extractor (though features may be derived from its output),
- Not MIR-specific (e.g., no pitch/onset logic),
- Not generic I/O or utilities.
