### 2. **What is IMBS?**
From context and known BGSLibrary structure:
- **IMBS** stands for **Improved Mixture-Based Subtraction**, or more precisely, it's the **IMBS (Improved Background Subtraction)** algorithm from the *BGSLibrary* project.
- It is a **pixel-level background modeling algorithm** that uses:
  - A histogram-based background model per pixel (bins),
  - Sampling over time,
  - Persistence maps,
  - HSV suppression (shadow removal),
  - Area thresholding,
  - Adaptive thresholds.

This is **not**:
- A Gaussian/GMM-based method (so not `lb`, `dp`, `T2F`)
- Not KDE-based (so not `KDE`)
- Not ViBe, VuMeter, SigmaDelta, TwoPoints (those are simpler per-pixel models)
- Not LBP_MRF or LBSP (those rely on texture/LBSP features)
- Not MultiLayer (which explicitly uses multiple layers/models)
- Not PBAS (which uses adaptive threshold per pixel with sample set and update rules, but different structure)
