### What is StaticFrameDifference?
From the name and typical usage in BGSLibrary:
- It performs **static frame difference**, i.e., subtracts the *first frame* (or a fixed reference frame) from the current frame.
- This is a **very basic pixel-wise differencing method**, often used as a baseline.
- No adaptive modeling, no learning, no complex statistics — just absolute difference + threshold.

### Key Insight:
In the official BGSLibrary (https://github.com/andrewssobral/bgslibrary), `StaticFrameDifference` is indeed implemented as a minimal background subtraction method that computes `|current - reference| > threshold`. It is often categorized alongside or as a variant of **SigmaDelta**, which is described as a *basic* differencing method.

Looking at the module descriptions again:
> **SigmaDelta**: This Sigma-Delta basic background subtraction algorithm module is used for foreground detection through simple per-pixel background estimation and differencing.

“Simple per-pixel background estimation and differencing” fits `StaticFrameDifference` perfectly — it estimates background as the first frame (a static estimate), then does per-pixel differencing with threshold.

Also, note that `StaticFrameDifference` does **not** adapt the background over time (unlike TwoPoints or PBAS), so it’s truly *static* — aligning with the most basic differencing idea embodied by SigmaDelta.
