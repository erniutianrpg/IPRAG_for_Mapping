### 2. **What is BGModelSom?**
- **SOM** stands for **Self-Organizing Map**, a type of unsupervised neural network used for clustering and vector quantization.
- In background subtraction, SOM-based models use a grid of neurons (each representing a prototype background color/pattern), trained online to adapt to background changes.
- This matches known background modeling approaches like those in:
  - *“Background Subtraction Using Self-Organizing Maps”* (e.g., work by J. M. Sánchez et al.)
  - Used in some variants of adaptive background modeling where pixel colors are mapped to a 2D SOM lattice.

So `BGModelSom` is a **background modeling algorithm based on Self-Organizing Maps**, which is:
- Non-parametric (no assumption about distribution),
- Pixel-level (operates per-pixel or per-region),
- Adaptive (updates via training steps and learning rates).
