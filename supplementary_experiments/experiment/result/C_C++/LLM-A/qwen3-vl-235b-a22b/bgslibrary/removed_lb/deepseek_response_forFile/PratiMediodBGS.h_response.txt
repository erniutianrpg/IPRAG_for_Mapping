### 2. **Algorithm Identification**
The class name `PratiMediodBGS` points to an algorithm by **Prati et al.** — specifically, the *Prati–Medoid* background subtraction method, which is a **pixel-wise adaptive background model using medoids** (a variant of k-medians/medoid clustering over time), often cited in background modeling literature (e.g., "Detecting Moving Objects in Video Sequences Using Medoid-Based Background Modeling").

Key characteristics:
- Uses a buffer of past pixels per location (`MEDIAN_BUFFER::pixels`)
- Computes a *medoid* (not mean or median) as background estimate
- Uses distance-based thresholds (`low_threshold`, `high_threshold`)
- Adaptive via sampling rate and history size
