The core logic uses **per-pixel codebooks**, where each pixel maintains a list of codewords (each with `min`, `max`, `f`, `l`, `first`, `last`). This matches the classic **CodeBook background subtraction algorithm** introduced by Kim et al. (2005), which models background as a set of codewords per pixel and classifies pixels based on whether their intensity falls within any codeword’s range.

Key characteristics:
- Non-parametric (no assumption of Gaussian or other distribution).
- Per-pixel adaptive codebook learning.
- Uses `alpha` (initial range half-width) and `beta` (update rate).
- Learning phase (`t <= learningFrames`) vs. detection phase.
