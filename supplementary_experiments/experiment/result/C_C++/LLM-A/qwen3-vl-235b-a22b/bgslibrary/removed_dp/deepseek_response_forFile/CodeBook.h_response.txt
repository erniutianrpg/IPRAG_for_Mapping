### 2. **What is the CodeBook Algorithm?**
The **CodeBook** background subtraction algorithm (originally by Kim et al., 2005) models each pixel as a codebook of codewords (each representing a color intensity history), where each codeword stores min/max intensity bounds, frequency, last update time, staleness flag, etc. It’s a **pixel-level, non-parametric, adaptive background model** using quantized color histograms per pixel.

Key characteristics:
- Non-parametric (no assumption on distribution like Gaussian).
- Pixel-wise codebook structure.
- Uses thresholds (`Tdel`, `Tadd`, `Th`) to add/remove codewords.
- Not based on KDE, MRF, LBP, fuzzy logic, or multi-layer modeling.
