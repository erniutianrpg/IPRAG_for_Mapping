### 1. **File identity and purpose**
- The class is `WeightedMovingMean`, derived from `IBGS` (Implements Background Subtraction).
- It implements a background subtraction algorithm that computes a weighted average of the current frame and two previous frames:

    `bg = 0.5 * current + 0.3 * prev1 + 0.2 * prev2`
  - Else: simple mean of three frames.
- Foreground is computed via absolute difference, optionally thresholded.
- It supports config saving/loading (parameters: `enableWeight`, `enableThreshold`, `threshold`, `showOutput`).
- Uses OpenCV (`cv::Mat`, `cv::absdiff`, `cv::threshold`, etc.).
