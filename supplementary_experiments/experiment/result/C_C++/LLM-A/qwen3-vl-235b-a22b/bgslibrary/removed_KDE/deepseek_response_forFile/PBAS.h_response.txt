### 2. **What is PBAS?**
PBAS (Pixel-Based Adaptive Segmenter) is a well-known background subtraction algorithm introduced by Hofmann et al. (2012). Its core ideas:
- Each pixel maintains a set of background samples (stochastic).
- Uses adaptive thresholds (`T`) and radii (`R`) per pixel.
- Incorporates learning rate adaptation based on foreground/background status.
- Often uses gradient/magnitude features (e.g., Sobel) to improve robustness.
- Parameters like `N` (number of samples), `Raute_min`, `R_lower`, `R_scale`, `T_init`, `T_inc`, `T_dec`, `alpha`, `beta` match exactly the PBAS paper’s notation.

The namespace `bgslibrary::algorithms::pbas` and class `PBAS` strongly confirm this is the PBAS algorithm implementation.
