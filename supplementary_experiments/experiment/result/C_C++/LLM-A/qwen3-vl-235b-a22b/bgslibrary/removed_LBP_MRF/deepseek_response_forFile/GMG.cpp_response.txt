### 2. **What is GMG?**
GMG stands for **Gaussian Mixture-based Background/Foreground Segmentation**, introduced by Godbehere, Matsukawa, and Goldberg (2012). It uses a per-pixel Gaussian mixture model (GMM) to model background, but with a probabilistic approach where each pixel maintains a set of samples (not full GMMs like MoG), and updates via Bayesian inference.

Crucially, **OpenCV’s `BackgroundSubtractorGMG`** implements exactly this algorithm.

So this file is a wrapper for that OpenCV algorithm within the `bgslibrary` framework.
