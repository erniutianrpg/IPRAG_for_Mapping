The Zivkovic AGMM is a well-known **Gaussian Mixture Model (GMM)**-based background subtraction algorithm, specifically an *adaptive* version that improves upon Stauffer & Grimson’s GMM by introducing:
- A complexity prior to avoid overfitting,
- Automatic mode pruning,
- Per-pixel adaptive learning rate,
- Threshold-based foreground classification (low/high thresholds).
