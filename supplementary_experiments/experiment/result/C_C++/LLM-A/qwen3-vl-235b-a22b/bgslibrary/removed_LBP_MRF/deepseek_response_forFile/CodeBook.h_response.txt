### 2. **What is the “CodeBook” algorithm?**
The CodeBook algorithm is a well-known background subtraction method based on **codebook modeling** of pixel color histories. Each pixel maintains a codebook of codewords (representing clusters of observed color values over time), where each codeword stores statistics like min/max intensity, frequency (`f`), last update time (`l`), etc. Foreground detection is done by checking if current pixel value matches any codeword within thresholds.

This algorithm was introduced by:
> Kim, J., et al. "Real-time foreground-background segmentation using codebook model." *Real-Time Imaging*, 2005.

It is **not** Gaussian-based, not KDE, not ViBe, not PBAS, not SigmaDelta, not LBSP, not T2F, etc.
