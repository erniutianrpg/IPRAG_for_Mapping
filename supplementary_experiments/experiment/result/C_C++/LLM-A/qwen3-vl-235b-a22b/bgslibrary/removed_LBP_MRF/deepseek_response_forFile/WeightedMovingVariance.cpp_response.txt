### 2. **Algorithm Behavior**
From the `process()` function:
- Maintains two previous frames (`img_input_prev_1`, `img_input_prev_2`)
- Converts current and previous frames to float (`CV_32F`)
- Computes a **weighted mean** over 3 frames (weights: 0.5, 0.3, 0.2 if `enableWeight=true`; otherwise equal weights)
- Then computes **weighted variance** for each frame relative to that mean, using the same weights
- Combines variances → takes square root → thresholding → foreground mask

This is a **pixel-level background model** based on **moving variance with weighted temporal smoothing**, not using Gaussian assumptions, kernel density, fuzzy logic, SOM, LBSP features, etc.

It resembles classical **temporal filtering / moving average / variance-based background modeling**, but with *explicit weighting* — more sophisticated than simple SigmaDelta or TwoPoints, but still fundamentally a *per-pixel statistical model*.
