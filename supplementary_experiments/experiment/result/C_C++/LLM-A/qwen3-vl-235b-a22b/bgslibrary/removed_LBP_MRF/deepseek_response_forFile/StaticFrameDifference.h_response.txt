### What is StaticFrameDifference?
This is a classic **frame difference** background subtraction method:  
- It compares the current frame with a static reference (e.g., first frame or a fixed background), computes absolute difference, applies threshold → binary foreground mask.
- Very simple, non-adaptive, pixel-wise, no learning — just static reference + threshold.
