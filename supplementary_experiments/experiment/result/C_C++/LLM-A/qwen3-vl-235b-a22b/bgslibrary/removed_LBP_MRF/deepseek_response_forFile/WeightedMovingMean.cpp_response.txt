### 1. **File Overview**
- Language: C/C++
- Includes: `"WeightedMovingMean.h"`
- Namespace: `bgslibrary`
- Functions:
  - `WeightedMovingMean::process(...)`: Implements a background subtraction algorithm using a weighted moving mean of the current and two previous frames.
  - `save_config`, `load_config`: For persistence of algorithm parameters (`enableWeight`, `enableThreshold`, `threshold`, `showOutput`).
- Core logic:
  - Maintains two previous frames (`img_input_prev_1`, `img_input_prev_2`).
  - Computes background model as a weighted average:  
    `0.5 * current + 0.3 * prev1 + 0.2 * prev2` (if `enableWeight == true`)  
    or simple average otherwise.
  - Foreground is computed via absolute difference, optionally thresholded.
  - No complex modeling (e.g., no Gaussian, no mixture, no kernel density, no fuzzy logic, no multi-layer, no LBSP features).

### 2. **Algorithm Type**
This is a **simple pixel-wise background estimation** using a **weighted moving average over 3 frames** — essentially an extension of a basic *moving mean* background model.

Key characteristics:
- Parametric, deterministic.
- No per-pixel adaptation (e.g., no learning rate, no update rule beyond shift buffer).
- Not non-parametric (so not KDE, VuMeter).
- Not based on Gaussian/GMM/SOM (so not lb).
- Not based on local binary patterns (so not LBSP).
- Not multi-layer (so not MultiLayer).
- Not ViBe, PBAS, SigmaDelta, T2F, IMBS, TwoPoints — those have distinct mechanisms (e.g., ViBe uses random sampling; PBAS uses adaptive thresholds per pixel; SigmaDelta uses delta modulation; TwoPoints uses two-frame differencing with memory).
- It's clearly a variant of **moving average**, which is a classic baseline method.
