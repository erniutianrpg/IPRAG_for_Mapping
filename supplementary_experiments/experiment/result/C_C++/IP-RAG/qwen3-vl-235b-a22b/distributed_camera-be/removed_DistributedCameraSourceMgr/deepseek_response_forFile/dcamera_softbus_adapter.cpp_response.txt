#### Functions & Behavior:

#### Namespace:

#### Core Responsibility:
This file **adapts the SoftBus communication layer** to the distributed camera use case — abstracting how sessions are created, managed, and how data/events flow through SoftBus for both source and sink roles. It does **not** handle:
- Camera control logic (e.g., start/stop preview)
- Data encoding/decoding
- Frame processing (pre/post)
- Virtual device implementation (HDF/HDI)
- High-level service coordination

It is purely about **channel-layer transport adaptation**.
