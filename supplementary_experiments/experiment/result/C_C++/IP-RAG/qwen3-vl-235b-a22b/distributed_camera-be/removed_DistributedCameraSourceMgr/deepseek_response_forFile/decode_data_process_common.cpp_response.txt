### 6. **Critical Differentiator: Pre vs Post Processing**
In distributed camera architecture:
- **Sink side (controlled)**: captures raw frames → preprocesses → encodes → sends over channel.
- **Source side (controller)**: receives encoded stream → **decodes** → post-processes (format/resolution/frame-rate adjustment) → displays or feeds to app.

This file:
- Takes `inputBuffers` (encoded packets)
- Decodes using `InitDecoder()`, `FeedDecoderInputBuffer()`, etc.
- Outputs decoded frames via `PostOutputDataBuffers()`
→ Clearly **post-processing on source side**.

Thus, **CameraDataPostProcess** is the best fit.
