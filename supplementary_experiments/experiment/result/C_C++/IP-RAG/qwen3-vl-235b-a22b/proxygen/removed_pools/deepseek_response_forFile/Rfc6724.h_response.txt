**What is RFC 6724?**  
RFC 6724 defines the *Default Address Selection for Internet Protocol Version 6 (IPv6)* — specifically, an algorithm to sort candidate destination addresses (e.g., IPv4 and IPv6 addresses returned by DNS) to select the "best" one for connection. This is used during address selection *after* DNS resolution but *before* establishing a connection.

So `rfc6724_sort` takes a list of resolved socket addresses (e.g., from DNS lookup) and reorders them according to RFC 6724 rules — typically used in client-side connection logic to prefer IPv6 over IPv4 when appropriate, avoid deprecated addresses, etc.
