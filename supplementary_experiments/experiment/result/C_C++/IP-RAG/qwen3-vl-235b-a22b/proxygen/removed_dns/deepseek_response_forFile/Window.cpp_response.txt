The `Window` class implements a **flow control window**, commonly used in HTTP/2 and HTTP/3 (QUIC) for managing stream-level or connection-level flow control:
- Tracks `capacity_` (window size limit)
- Tracks `outstanding_` (bytes sent but not yet acknowledged)
- Provides methods to `reserve()` (consume window), `free()` (release window), `setCapacity()`, etc.
- Includes overflow/underflow protection using `int32_t` arithmetic (critical for HTTP/2 window updates, where window sizes are signed 31-bit integers per RFC 7540)
