### 2. **Understanding WPT in Context**
- WPT is a generalization of the Discrete Wavelet Transform (DWT), where *both* approximation and detail coefficients are further decomposed at each level.
- It is fundamentally a **filter bank-based decomposition**, implemented via convolution with wavelet filters (low-pass/high-pass).
- The code uses:
  - `ConvObj` from `dsp/conv_algorithm.h` → indicates use of convolution primitives (likely FFT-based or direct convolution).
  - `dwt_filterCoef` from `filterbank/...` → constructs wavelet filter coefficients (e.g., Symlets), which is part of filter bank design.
- However, the *purpose* of this module is not to provide generic filter banks (like mel, bark, gammatone), but to implement a specific **transform algorithm** (WPT) that relies on filter banks and convolution as building blocks.
