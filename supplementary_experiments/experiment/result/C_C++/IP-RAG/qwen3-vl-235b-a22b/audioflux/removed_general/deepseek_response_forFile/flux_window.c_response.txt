### 3. **What is a window function?**
In DSP, window functions are applied before FFTs (e.g., in STFT) to reduce spectral leakage. They are *foundational building blocks* used in:
- Short-time Fourier transform (STFT)
- Filter design
- Spectral analysis
- Audio resampling preprocessing

They are **not** features themselves (so not `feature`), nor do they implement filter banks (`filter_bank`) or high-level MIR tasks (`mir`). Instead, they provide low-level algorithmic support required *by* those modules.
