### 2. **What is NSGT?**
- NSGT is a *generalized short-time Fourier transform* with non-uniform (e.g., logarithmic/octave-based) frequency resolution.
- It is used for **time-frequency analysis**, especially in audio and music processing where perceptual scales (e.g., mel, ERB, octaves) are desired.
- Unlike STFT (uniform bins), NSGT allows flexible, adaptive filter banks — often constructed using Gabor frames or wavelet-like filters.
- Crucially, NSGT is **not itself a feature extractor**, but a *transform* that produces a time-frequency representation, which can then be used for feature extraction or MIR tasks.
