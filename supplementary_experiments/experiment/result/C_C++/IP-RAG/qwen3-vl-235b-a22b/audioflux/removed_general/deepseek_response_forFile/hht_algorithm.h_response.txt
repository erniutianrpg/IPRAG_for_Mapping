### 2. **What is HHT?**
- Hilbert–Huang Transform is a **time-frequency analysis method** for non-stationary and nonlinear signals.
- It decomposes a signal into Intrinsic Mode Functions (IMFs) via EMD, then computes instantaneous frequency/amplitude via Hilbert transform.
- Used in signal processing for analyzing transient, non-sinusoidal, or modulated signals — common in biomedical, mechanical vibration, and audio analysis (e.g., for transient-rich sounds).
