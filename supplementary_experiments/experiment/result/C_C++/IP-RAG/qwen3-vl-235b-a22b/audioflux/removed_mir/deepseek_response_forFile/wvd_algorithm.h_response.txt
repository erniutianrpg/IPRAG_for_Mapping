### 2. **What is WVD?**
- The Wigner–Ville Distribution is a *time-frequency transform*, specifically a *bilinear* (quadratic) transform.
- It provides high-resolution joint time-frequency analysis but suffers from cross-term interference.
- It is **not** a linear transform like STFT or wavelet; it's a higher-order time-frequency representation.
- In audio/signal processing systems, WVD is typically grouped with other time-frequency transforms (e.g., STFT, Gabor, synchrosqueezing, reassignment), especially when implemented as a reusable algorithmic component.
