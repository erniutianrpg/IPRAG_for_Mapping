### 2. **What is CQT?**
Constant-Q Transform is a time-frequency representation where frequency bins are logarithmically spaced (octave-based), mimicking human auditory perception. It is:
- A **time-frequency transform**, like STFT or wavelet transforms.
- Often used as a **front-end** for perceptual audio features (e.g., chroma, CQCC, CQHC).
- Involves constructing a filter bank (log-spaced bandpass filters), applying them (often via FFT-based convolution or direct filtering), and possibly post-processing (deconvolution, DCT, resampling).

The file implements the full pipeline: filter bank design → STFT/resampling → CQT computation → feature derivation (chroma, CQCC, etc.).
