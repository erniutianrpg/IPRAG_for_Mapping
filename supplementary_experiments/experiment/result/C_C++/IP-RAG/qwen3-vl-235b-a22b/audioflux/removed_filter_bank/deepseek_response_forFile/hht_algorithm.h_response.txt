### 2. **What is HHT?**
The **Hilbert–Huang Transform** is a time-frequency analysis method designed for non-stationary and nonlinear signals. It consists of:
- **Empirical Mode Decomposition (EMD)**: decomposes a signal into intrinsic mode functions (IMFs).
- **Hilbert transform**: applied to each IMF to obtain instantaneous frequency and amplitude.

It is a **time-frequency transform**, similar in purpose to STFT, wavelet transforms, or synchrosqueezing — but distinct in methodology (adaptive, data-driven decomposition).
