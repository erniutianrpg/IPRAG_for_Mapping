### 2. **What is CQT?**
- Constant-Q Transform is a time-frequency representation where frequency bins are logarithmically spaced (octave-based), mimicking human auditory perception.
- It is **not** a standard STFT; it’s a specialized transform used heavily in **music information retrieval (MIR)** because of its suitability for pitch/harmonic analysis.
- CQT is foundational for:
  - Chroma features (pitch class representation),
  - CQ-cepstrum (CQCC),
  - Harmonic analysis (CQHC),
  - Deconvolution for source/filter separation (e.g., vocal tract modeling).
