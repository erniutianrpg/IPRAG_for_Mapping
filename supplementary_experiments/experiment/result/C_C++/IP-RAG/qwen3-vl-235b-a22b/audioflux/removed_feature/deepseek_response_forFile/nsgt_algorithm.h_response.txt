### 2. **What is NSGT?**
Non-Stationary Gabor Transform is a *time-frequency analysis* method that generalizes the Short-Time Fourier Transform (STFT) using non-uniform, adaptive filter banks—often designed to follow perceptual or musical scales (e.g., constant-Q, mel, ERB). It is *not* a simple STFT; it's a more flexible, adaptive time-frequency representation built upon *custom spectral filter banks*.

Key point: NSGT is fundamentally about constructing and applying a *structured filter bank* over time-frequency space, where the filters are not fixed (like in STFT), but designed based on frequency scale, bin density, normalization, etc.
