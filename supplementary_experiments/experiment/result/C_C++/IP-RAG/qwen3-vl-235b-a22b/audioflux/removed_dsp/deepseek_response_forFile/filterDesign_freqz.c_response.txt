#### b. `filterDesign_freqzSOS(...)`

- Iteratively computes frequency response of each section and multiplies them (complex multiplication via `__vcmul`).

#### c. `filterDesign_calFreResponse(...)`
- Core routine: evaluates DTFT of a real coefficient vector at given frequencies:
  ```
  X(ω) = Σ_{n=0}^{N-1} x[n] * e^{-jωn}
        = Σ x[n] cos(ωn) - j Σ x[n] sin(ωn)
  ```
  (Note: sign is `-ωn`, consistent with standard DTFT convention.)
