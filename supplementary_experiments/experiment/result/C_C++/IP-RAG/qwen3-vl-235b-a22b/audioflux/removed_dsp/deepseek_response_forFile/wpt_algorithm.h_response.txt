### 2. **What is WPT?**
- WPT is a **time-frequency analysis** technique used in signal processing.
- It provides a more flexible decomposition than DWT by splitting both approximation and detail coefficients at each level.
- Used in applications like denoising, feature extraction, compression, and pattern recognition — especially where high-resolution frequency subbands are needed.
- In audio processing, it can be used for spectral analysis, transient detection, or as a front-end for feature extraction.
