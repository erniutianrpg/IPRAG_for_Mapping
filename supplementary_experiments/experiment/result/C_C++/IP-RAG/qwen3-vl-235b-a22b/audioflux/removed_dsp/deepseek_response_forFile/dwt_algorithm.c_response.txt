### 2. **What is DWT?**
- DWT is a **time-frequency transform**, decomposing a signal into approximation and detail coefficients at multiple scales.
- It is a **multiresolution analysis** tool, widely used in signal processing, denoising, compression, and feature extraction.
- In audio, DWT can be used for:
  - Time-frequency representation (like spectrogram but with dyadic scaling),
  - Feature extraction (e.g., wavelet packet features),
  - Preprocessing before higher-level analysis (e.g., MIR or feature modules).

However, **the DWT itself is not a feature extractor per se**, nor is it directly part of MIR (e.g., pitch/onset) or filter banks (like Mel, Gammatone, or constant-Q). It is a **transform primitive**, similar to STFT, CQT, or synchrosqueezing.
