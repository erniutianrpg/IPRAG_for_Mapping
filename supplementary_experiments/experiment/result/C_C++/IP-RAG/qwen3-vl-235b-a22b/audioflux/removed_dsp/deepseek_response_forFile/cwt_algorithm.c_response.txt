### 2. **What is CWT?**
- CWT is a **time-frequency analysis** technique.
- It decomposes a signal into time-localized frequency components using wavelets (e.g., Morse wavelets).
- Unlike STFT/spectrogram, CWT provides variable resolution (high time res at high freq, high freq res at low freq).
- Often used in audio analysis for transient detection, onset detection, or as a front-end for feature extraction (e.g., in bioacoustics, speech, music).

In this code:
- The filter bank is explicitly built for CWT (`cwt_filterBank.h`), not generic auditory filters (though `auditory_filterBank.h` is included—possibly for reuse or comparison).
- The core operation is computing wavelet coefficients across scales/frequencies — i.e., generating a **time-scale representation**, analogous to a spectrogram but with wavelet basis.
