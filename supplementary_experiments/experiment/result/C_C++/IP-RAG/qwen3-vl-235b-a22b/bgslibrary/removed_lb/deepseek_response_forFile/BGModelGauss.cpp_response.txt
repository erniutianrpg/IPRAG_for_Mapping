### 2. **Content Analysis**
The class `BGModelGauss` implements a **Gaussian background model**:
- Maintains per-pixel mean (`m_pMu`) and variance (`m_pVar`) as `DBLRGB` (double-precision RGB).
- Uses a **single Gaussian per pixel** (not GMM — no multiple components).
- Update rule:
  - Foreground detection via Mahalanobis distance:  
    `d² = Σ (src - μ)² / σ² < threshold`
  - Mean update: `μ ← μ + α * (src − μ)`
  - Variance update: `σ² ← σ² + α * ((src − μ)² − σ²)`
  - Clamped to `m_noise` (maximum variance).
- Parameters are tunable via `setBGModelParameter`: threshold, noise (variance ceiling), learning rate (`α`).
- Initialization sets initial mean to first frame, variance to `m_noise`.

This is a classic **single Gaussian background model**, often called **"Gaussian Mixture Model with K=1"**, or simply **"Adaptive Gaussian Background Subtraction"**, distinct from:
- GMM (e.g., MOG/MOG2 which use multiple Gaussians),
- Non-parametric methods (KDE, ViBe, VuMeter),
- Pixel-level adaptive thresholding like PBAS or SigmaDelta,
- Texture/LBP-based methods (LBSP, LBP_MRF).
