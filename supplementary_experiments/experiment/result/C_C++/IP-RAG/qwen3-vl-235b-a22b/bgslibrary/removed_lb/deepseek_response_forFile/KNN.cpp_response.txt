### 2. **What is the KNN Background Subtraction Algorithm?**
The KNN background subtraction method:
- Models each pixel as a set of samples (history).
- For a new frame, computes distance to nearest K neighbors.
- Classifies pixel as foreground if distance > threshold.
- Supports shadow detection (via `shadowThreshold`).
- It is a **pixel-level**, **non-parametric**, **adaptive** background modeling method — but distinct from KDE, ViBe, or PBAS.

It is **not**:
- A Gaussian mixture model (like MOG2),
- Not based on LBP/LBSP features,
- Not MRF/graph-based (like LBP_MRF),
- Not fuzzy (T2F), not Sigma-Delta, not TwoPoints, not IMBS, not PBAS, etc.
