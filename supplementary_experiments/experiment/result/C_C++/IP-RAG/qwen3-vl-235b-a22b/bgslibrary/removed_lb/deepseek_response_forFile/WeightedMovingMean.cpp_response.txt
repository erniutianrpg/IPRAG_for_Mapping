- The file implements a class `WeightedMovingMean`, which inherits from `IBGS` (likely an interface/base class for background subtraction algorithms in BGSLibrary).
- It performs background modeling using a **weighted moving average** of the current frame and two previous frames:

    `bg = 0.5 * current + 0.3 * prev1 + 0.2 * prev2`

- It supports configuration saving/loading (via OpenCV’s `FileStorage`), and has debug/logging infrastructure.
