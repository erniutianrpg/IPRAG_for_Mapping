- In background subtraction, it’s used to combine multiple cues (e.g., color difference, texture difference, motion) using fuzzy measures (e.g., λ-fuzzy measures) to produce a robust foreground mask.
- This is **not** a standard parametric model like Gaussian, nor a pure non-parametric KDE/VuMeter/IMBS.
- It is specifically a **fuzzy fusion-based** approach that integrates multiple features — here, color and LBP texture.
