### 2. **Algorithm Behavior (from code)**
The class `MeanBGS` implements:
- A **per-pixel background model** using the **running mean** of pixel values.
- Initialization: copies first frame into `m_mean`.
- Update: exponential moving average (EMA) with learning rate `Alpha`:  
  `mean = α * old_mean + (1−α) * current_pixel`
- Subtraction: computes squared Euclidean distance between current pixel and background mean, compares to low/high thresholds → binary foreground/background masks.

This is a **classic, simple pixel-level background subtraction method**, often called:
- “Mean-based background subtraction”
- Or sometimes “Simple Mean Background Model”

It is **parametric**, **pixel-wise**, and **adaptive** via exponential averaging — very similar in spirit to SigmaDelta (which also uses per-pixel estimation and differencing), but **SigmaDelta** typically refers specifically to a *delta-based* update (e.g., maintaining a running difference or thresholded delta), whereas this is explicitly a *mean* model.
