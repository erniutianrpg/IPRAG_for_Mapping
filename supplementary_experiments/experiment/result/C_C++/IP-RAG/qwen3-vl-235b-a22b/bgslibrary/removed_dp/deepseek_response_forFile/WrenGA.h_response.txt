- `WrenGA`: Inherits from `Bgs`, implements:
  - `InitModel()`: initializes background model (per-pixel Gaussian).

  - `Update()`: updates background model using `update_mask`.

  - `SubtractPixel()`: per-pixel subtraction using Gaussian distance and thresholds.
  - `Background()` returns estimated background image.

This is clearly a **pixel-level parametric background model** based on **single Gaussian per pixel**, with adaptive learning and dual-threshold foreground detection.

### 4. **Key Differentiator: Is WrenGA part of the “lb” family?**

While `WrenGA` doesn’t start with “LB”, it is *functionally identical* to `LBGaussian` (which is a simple Gaussian model), and in many forks, `WrenGA` is considered a variant of that class.

But crucially: the candidate list does **not** include a standalone “Gaussian” or “SimpleGaussian” module. Among all options, **lb** is the *only* one that explicitly covers *simple Gaussian* background modeling.
