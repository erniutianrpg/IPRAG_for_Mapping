### 3. **What is “Frame Difference”?**
- In background subtraction literature, *Frame Difference* (or *Temporal Difference*) is one of the simplest methods:
  - Compute absolute difference between current frame and previous frame (or N-frame delay).
  - Apply threshold to get binary foreground mask.
  - No explicit background model beyond storing previous frame(s).
  - Often used as baseline or preprocessing step.

This matches exactly:
- No complex modeling (no Gaussian, KDE, MRF, fuzzy logic, etc.).
- Pure pixel-wise temporal differencing + threshold.
- Minimal state (just previous frame implicitly stored — though not shown in header, likely in `.cpp`).
