### 2. **What is GMG?**
The GMG algorithm is a **pixel-level probabilistic background modeling method** based on **Gaussian Mixture Models (GMM)**, but with key differences from standard GMM (e.g., MOG/MOG2):
- It uses a **Bayesian nonparametric approach** where each pixel maintains a set of samples (not fixed Gaussians), updated via kernel density estimation.
- It incorporates **temporal consistency** and **spatial smoothing** (via morphological operations or MRF-like post-processing).
- It's *not* the same as the classic Stauffer & Grimson GMM (used in MOG/MOG2), though both are GMM-based.

In BGSLibrary, GMG is implemented as a wrapper around OpenCV’s `BackgroundSubtractorGMG`, which itself implements the Godbehere et al. method.
