### 2. **Algorithm Behavior (from code)**
Key logic in `process()`:
- Converts input to grayscale.
- Maintains a background model (`img_background`) as a running average (float image scaled 0–1).
- Computes absolute difference between current frame and background → foreground mask.
- Applies thresholding + median blur for noise reduction.
- Two-phase learning:
  - **Initial learning phase** (if `learningFrames > 0` and `counter <= learningFrames`): updates background globally using `alphaLearn`.
  - **Steady-state phase**: updates background *only at background pixels* (where `img_foreground == 0`, i.e., not foreground), using `alphaDetection`. This is **selective updating** — only pixels classified as background are updated.
- Parameters: `alphaLearn`, `alphaDetection`, `threshold`, `learningFrames`.

This is a **pixel-wise adaptive background model with selective update**, where background update is conditioned on foreground detection — i.e., it avoids updating background where motion/foreground is present.
