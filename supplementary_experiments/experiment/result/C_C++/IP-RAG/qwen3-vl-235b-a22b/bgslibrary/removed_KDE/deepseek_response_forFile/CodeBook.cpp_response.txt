### 1. **File Context & Content Overview**
- The file implements a class `CodeBook`, which inherits from `IBGS` (likely “Independent Background Subtraction” or similar base interface in BGSLibrary).
- It uses a **codebook-based background modeling** approach:
  - Each pixel maintains a *codebook* — a list of codewords (`std::vector<codeword>` per pixel).
  - A codeword contains `min`, `max`, `f` (frequency), `l` (lapse/age), `first`, `last`.
  - During learning: new codewords are added if pixel value doesn’t match any existing codeword interval `[min, max]`.
  - During update: intervals are adaptively adjusted using parameters `alpha` (initial tolerance) and `beta` (update rate).
  - Foreground detection: a pixel is foreground if its intensity falls outside all codeword intervals.
- This is the classic **CodeBook algorithm** introduced by Kim et al. (2005), *"Real-Time Foreground-Background Segmentation Using Codebook Model"*.

- Non-parametric (uses empirical codebooks, not Gaussian or mixture models).
