- The KNN algorithm (Zivkovic, 2006/2007) is a **pixel-wise, non-parametric** background modeling method.
- For each pixel, it maintains a set of recent samples (history), and classifies new pixels based on distance to the K nearest neighbors among those samples.
- It is **not Gaussian-based**, **not mixture-model-based**, and **not fuzzy or SOM-based** — it’s a **non-parametric, sample-based** method.
- OpenCV’s `BackgroundSubtractorKNN` implements this exact approach.
