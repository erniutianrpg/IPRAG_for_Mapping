### 2. **Algorithm Behavior (from code)**
Key logic in `process()`:
- Converts input to grayscale.
- Maintains a background model (`img_background`) as a running average.
- Uses two learning rates:
  - `alphaLearn`: used during initial learning phase (`learningFrames > 0 && counter <= learningFrames`)
  - `alphaDetection`: used after learning phase, *only updates background where foreground = 0* (i.e., selective update based on foreground mask).
- Foreground is computed via absolute difference between current frame and background, thresholded and median-blurred.
- Background update is **selective**: only pixels classified as background are updated using `alphaDetection`.
- This matches the description of **"Adaptive Selective Background Learning"**, which is known in literature (e.g., related to approaches like those in *Stauffer & Grimson*, or *Zivkovic*’s adaptive background modeling with selective update).

This is **not**:
- A GMM-based method (so not `lb`, `T2F`, `dp` if they’re GMM-focused),
- Not KDE (no kernel density estimation),
- Not ViBe (no random sampling from neighborhood),
- Not PBAS (no pixel-level adaptive thresholds per pixel with multiple samples),
- Not SigmaDelta (which is simpler, single-value per pixel with delta update),
- Not IMBS, TwoPoints, VuMeter — these are specific named algorithms with distinct mechanisms.
