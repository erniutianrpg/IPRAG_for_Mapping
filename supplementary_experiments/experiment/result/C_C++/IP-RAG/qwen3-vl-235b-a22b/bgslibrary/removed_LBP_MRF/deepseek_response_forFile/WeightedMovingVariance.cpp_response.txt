### 1. **File Context & Purpose**
- The class is named `WeightedMovingVariance`.
- It inherits from `IBGS`, indicating it's a background subtraction algorithm in BGSLibrary.
- The core logic computes a **weighted moving average** of the current and two previous frames, then computes a **weighted variance** (i.e., squared deviation from the weighted mean), followed by taking the square root (standard deviation), thresholding, and outputting foreground mask.
- Key behavior:
  - Maintains 2 previous frames (`img_input_prev_1`, `img_input_prev_2`).
  - Computes a weighted mean: e.g., `0.5 * current + 0.3 * prev1 + 0.2 * prev2`.
  - Computes weighted variance per pixel: `(pixel - mean)^2 * weight`, summed across frames.
  - Outputs foreground via threshold on standard deviation.

This is clearly a **pixel-level background model** using a **moving window with exponential/weighted decay**, not based on Gaussian mixtures, KDE, fuzzy logic, LBSP features, or multi-layer models.
