### 2. **What is Static Frame Difference?**
- A classic, simple background subtraction technique:
  - Maintains a *static* background model (e.g., first frame or average of initial frames).
  - For each new frame, computes pixel-wise absolute difference with the background model.
  - Applies a fixed threshold to classify pixels as foreground/background.
- This is **not** adaptive per-pixel (unlike ViBe, PBAS, SigmaDelta), nor does it use statistical models (GMM, KDE, fuzzy, etc.), nor multi-layer or feature-based approaches (LBSP, MultiLayer).
