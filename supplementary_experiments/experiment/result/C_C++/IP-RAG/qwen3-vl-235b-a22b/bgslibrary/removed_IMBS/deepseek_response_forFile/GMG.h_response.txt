Let’s analyze the file `bgslibrary\algorithms\GMG.h` step by step:

### 1. **File Content Summary**
- The header defines a class `GMG` in namespace `bgslibrary::algorithms`.
- It inherits from `IBGS` (a base interface/class for background subtraction algorithms in BGSLibrary).
- It uses OpenCV’s `cv::BackgroundSubtractorGMG`, which is OpenCV’s implementation of the **Gaussian Mixture Model-based background subtraction algorithm** proposed by **Godbehere, Matsukawa, and Goldberg (GMG)** — *not* to be confused with Stauffer & Grimson’s GMM (which is often called “MOG” or “MOG2” in OpenCV).
- The GMG algorithm is a **non-parametric**, **pixel-wise probabilistic background model** that uses kernel density estimation (KDE) over color histograms per pixel, with adaptive learning and Bayesian inference for foreground detection.
  - Specifically, GMG models each pixel as a mixture of color samples (histograms), using a **KDE-like approach** (though not exactly classical KDE — it uses a discrete histogram approximation with a decaying memory).
  - It was introduced in: *A. Godbehere, A. Matsukawa, K. Goldberg, "Visual Tracking of Human Visitors under Variable-Lighting Conditions for a Responsive Audio Art Installation", IEEE/RSJ IROS 2012*.
- The class includes:
  - `fgbg`: an OpenCV `Ptr<cv::BackgroundSubtractorGMG>` — this confirms direct use of OpenCV’s GMG implementation.
  - Configuration parameters: `initializationFrames`, `decisionThreshold`, etc.
  - Standard `process()`, `save_config()`, `load_config()` methods.
