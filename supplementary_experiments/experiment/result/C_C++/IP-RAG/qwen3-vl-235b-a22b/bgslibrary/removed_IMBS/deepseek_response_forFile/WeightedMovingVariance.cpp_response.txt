### 1. **File Context & Purpose**
- The class `WeightedMovingVariance` inherits from `IBGS`, indicating it is a background subtraction algorithm.
- It implements a **weighted moving variance** approach:
  - Uses three frames: current (`img_input`), previous (`img_input_prev_1`), and second-previous (`img_input_prev_2`).
  - Computes a weighted mean (e.g., 0.5, 0.3, 0.2) of these frames.
  - Then computes a **weighted variance** per pixel using `computeWeightedVariance`, which likely computes squared deviations scaled by weights.
  - Takes square root → standard deviation image → thresholding → foreground mask.
- No complex modeling (no GMM, no KDE, no fuzzy logic, no MRF, no LBP/LBSP features).
- It is **pixel-level**, uses simple arithmetic operations (mean, variance, threshold), and maintains only short-term history (2 prior frames).
- It does **not** use histograms, kernels, texture features, or multi-layer models.
