### 2. **Core Algorithm Behavior (from code excerpt)**

The `process()` function:
- Maintains two previous frames (`img_input_prev_1`, `img_input_prev_2`) in addition to current frame.
- Converts frames to float (0–1 range).
- Computes background as a **weighted linear combination** of current and two previous frames:
  - If `enableWeight == true`:  
    `bg = 0.5 * current + 0.3 * prev1 + 0.2 * prev2`
  - Else: simple average: `(current + prev1 + prev2) / 3`
- Then computes foreground via absolute difference and optionally thresholds.

This is a **pixel-wise, temporal averaging** method — specifically, a **weighted moving mean**, i.e., a variant of **simple moving average** with non-uniform weights.
