- **Assigned Module**: [feature]

The file `src\flux_spectral.c` contains functions that compute various spectral features such as spectral flatness, flux, rolloff, centroid, spread, skewness, kurtosis, entropy, crest, slope, decrease, bandwidth, RMS, HFC, SD, SF, MKL, and energy. These are all standard audio features extracted from spectral data, which aligns perfectly with the purpose of the `feature` module. The `feature` module is specifically designed for extracting audio features from spectral, cepstral, and time-domain data, and the functions in this file directly correspond to its functionality. The other modules (`dsp`, `general`, and `mir`) do not fit as well because they focus on different aspects like low-level signal processing, general algorithms, or music information retrieval, respectively.
