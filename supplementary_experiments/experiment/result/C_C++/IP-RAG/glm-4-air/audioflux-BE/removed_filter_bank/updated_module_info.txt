ModuleDescriptions : {
    "This module mainly corresponds to low-level digital signal processing capabilities, providing foundational algorithm support for upper-level transforms, spectra, filtering, and audio processing. It supports the Short-time Fourier transform, BFT/STFT-style transforms, spectrograms at different frequency scales, audio resampling, complex-spectrum phase extraction, and other basic processing."
    "This module is used to extract audio features from spectral, cepstral, and time-domain data. It mainly covers Spectral, XXCC, Deconv, Cepstrogram, Temporal, and FeatureExtractor functionality: Spectral computes various spectral features, XXCC extracts cepstral coefficients, Deconv performs spectral deconvolution, Temporal extracts time-domain features such as energy, RMS, and zero-crossing rate, and FeatureExtractor supports batch feature extraction."
    "This module is the core general algorithm layer of AudioFlux, centralizing major time-frequency transforms, spectral computation, basic audio I/O, and common utilities. It provides spectrogram generation as well as multiple time-frequency transforms, synchrosqueezing, reassignment algorithms, audio reading, writing, mono conversion, resampling, and other common capabilities."
    "This module targets music information retrieval tasks, mainly including pitch estimation, onset detection, harmonic/percussive separation, harmonic analysis, pitch shifting, and time stretching. It is used to extract music-semantics-related information from audio, such as fundamental frequency/pitch, onset, HPSS, and harmonic ratio, and provides processing algorithms such as pitch shift and time stretch."
