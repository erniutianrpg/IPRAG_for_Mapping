# Analysis of src/filterbank/auditory_filterBank.c

## File Content Overview
This file contains implementations for constructing and applying various types of spectral filter banks and auditory weights. The functions include:

1. **Core filter bank construction functions**:
   - `__auditory_estiFilterBank()`
   - `__auditory_slaneyFilterBank()`
   - `__auditory_gammatoneFilterBank()`
   - `__auditory_windowFilterBank()`
   - `__auditory_linearFilterBank()`
   - `auditory_filterBank()` (main public interface)

2. **Frequency mapping functions**:
   - Functions to convert between different frequency scales (Mel, Bark, Erb, etc.)
   - Functions to convert between linear and logarithmic scales

3. **Auxiliary functions**:
   - `__auditory_calBandEdge()` for calculating band edges
   - `__reviseMidiFre()`, `__reviseLogFre()`, etc. for frequency revision

The file includes dependencies on vector operations, complex numbers, window functions, and filter design utilities.
