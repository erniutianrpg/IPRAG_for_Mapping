ModuleDescriptions : {
    "This module is responsible for lifecycle, state machine, controller, input stream, data processing, IPC service, and callback management on the source side, namely the controller side, enabling the controller to invoke distributed camera capabilities and use the controlled device's camera for preview, photo capture, video recording, and related functions."
    "This module is responsible for lifecycle, access control, controller, data processing, image/video output, event notification, and IPC services on the sink side, namely the controlled side, enabling the controlled side to receive commands from the controller and use the local camera to provide image data to the controller."
    "This module provides common channel-layer capabilities, including SoftBus adaptation, session management, channel interfaces, and channel listener interfaces. It is the communication foundation for transmitting control commands and image data between the source side and sink side."
    "This module is responsible for the controller-side channel implementation. It establishes connections with the controlled side through SoftBus, sends camera control commands on the controller side, and receives image information returned by the controlled side."
    "This module is responsible for the controlled-side channel implementation. It communicates with the controller through SoftBus, receives camera commands from the controller, and sends image information from the controlled side back to the controller."
    "This module provides common data processing frameworks, data processing pipeline interfaces, codecs, color space conversion, frame-rate control, image types, and other common capabilities, supplying foundational components for data processing flows on both the source and sink sides."
    "This module is responsible for the data preprocessing pipeline on the sink side or input side, processing image data returned by the camera framework or collected locally before it enters the transmission/encoding flow."
    "This module is responsible for the data post-processing pipeline on the source side or output side. It decodes, converts formats, and processes frame rate, resolution, and related properties of received image data so that the controller can use distributed camera data as if using a local Camera."
    "This module implements distributed virtual Camera devices, Host, Provider, Device, Stream Operator, Metadata processing, and related IPC proxies/callbacks at the HDF/HDI layer, enabling the distributed camera to be recognized, loaded, and used by the multimedia framework as virtual hardware."
    "This module provides common distributed camera utilities, data buffers, indexes, constants, error codes, and general support capabilities related to CameraClient/CameraOperator, including local camera query, open, close, stream acquisition, and preview/photo/video callback handling."
